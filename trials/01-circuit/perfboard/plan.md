## 基板の大きさと枚数

**9×15cm の片面の板を1枚使う。** 持ち主が買う 10 枚セット（5×7cm・7×9cm を 4 枚ずつ、9×15cm を 2 枚。片面、厚さ 1.2mm）の中の1枚。

- 手元の板（片面 15×25 穴 ×2、両面 28×6 穴 ×1）は使えなかった。まとまりが4つ（電源の入口と LED の口、ドライバ3台とモータの口、ESP32、エンコーダの口）あるのに、板が3枚しかない。ESP32 だけで 15×25 穴の板の半分以上を使う。
  無理に詰めると、12V と GND の母線の間が穴1つ分を切り、C1・C2 がドライバに触れ、板どうしの線が約 20 本になる。
- 160×115mm は大きすぎる（持ち主）。9×15cm は 150×90mm。
- **1枚（9×15cm）にした理由**（7×9cm を2枚に分ける形と比べた）:
  - 2枚に分けると、板をまたぐ線が 11 本になる（IN 6 本、VREF、電池電圧、LED の信号、5V、SGND）。はんだの所が 22 か所増え、取り付けも2枚ぶん要る。
  - 2枚に分けると、SGND を GND-STAR へつなぐ1本（NT1）が板をまたぐ線になる。これが外れると、USB をつないだまま12V を入れたとき、ESP32 の GPIO とドライバの GND の電位が決まらなくなる。1枚なら NT1 は基板の上の短い線で、外れにくい。
  - 7×9cm を2枚にするのは、03 で 150×90mm を置く場所が取れないとき。そのときは行 14 と 15 の間で切り、上の帯と下の帯を別の板にする。図の配置はほぼそのまま使える。
- **穴の数**: 9×15cm の板は売り手によって 30×48 穴から 34×53 穴まである。配置は少ないほう（**30 行 × 48 列**）に収めた。
  多い板では、左上の穴から数えて、余りを右と下に残す。届いたら穴を数える（[procedure.md](./procedure.md) の工程 0）。
- 板の色が緑ならガラスエポキシ（ランドがはがれにくい）。茶色・薄茶なら紙フェノールで、熱でランドがはがれやすい。そのときは、こてを当てる時間を短くし、電流はランドではなく線に流す（もともとそういう配置にしてある）。

## 部品の置き場所

図: [layout-top.svg](./layout-top.svg)。座標の一覧は [wires.md の「部品の位置」](./wires.md#部品の位置)。

### 上の帯（行 1〜14）: 12V・モータ

```
行  1 ┌───────────────────────────────────────────────────────────────┐
    │ TP2 U4(5V)       [J2 輪0]         [J5 輪1]         [J7 輪2]      │← モータの線（上の辺）
    │  C13  F2┐   C10          C11              C12                    │
行  6│ TP-G │   ┊ ║U1 ドライバ║      ║U2 ドライバ║      ║U3 ドライバ║   │
行  7│ NT1  │   ┊ （立てる）           （立てる）           （立てる）       │
行 10│J9 ━━ C1 ━━ D3 ━━━━━━━ PGND の母線 ━━━━━━━━━━━━━━━━━━━━━━━━━━ C2 │
    │(−)   ┃(島)          C7              C8               C9   TP7      │
行 12│J9 ━━ C1 ━━━━━━━━━━━━ VM の母線 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ C2 │
    │(+)  TP1   F2    R1                                       TP6        │
行 14└───────────────────────────────────────────────────────────────┘
```

- **母線**: PGND を行 10、VM を行 12 に、左の J9 から右の C2 まで、裸のすずめっき線で引く。間の行 11 には何も付けない（12V と GND の間を穴1つ分あける）。
- **C1**（入口の 1000µF）は J9 のすぐ右（列 7）。**C2**（2個目の 1000µF）はいちばん右、U3 のそば（列 46）。circuit.md §7 のとおり。
- **ドライバ U1〜U3** は、1×8 のソケットを行 7 に横向きに並べ、10 列おき（25.4mm）に置く。1 番（GND）を左にする。
  ドライバは付属の L 字のピンヘッダで立つ。どちらの側に倒れて立つか（L 字をどちら向きに付けたか）は分からないので、ソケットの上下 1 行ずつには部品を置かず、線だけを通す（図の灰色の点線の四角）。
- 各ドライバの足の行き先:
  - OUT1・OUT2（6・8 番）は、真上のモータの端子台（行 3）へ。
  - GND（1 番）と RS（7 番）は、下の PGND の母線へ。
  - VM（5 番）は、下の口（行 8）から表の線 W01〜W03 で PGND の母線をまたいで VM の母線へ。
    ドライバの足の並び（GND・IN2・IN1・VREF・VM・OUT1・RS・OUT2）では、VM が GND と RS の間にあるので、どう引いても1本はまたぐ。
  - VREF（4 番）は、上の C10〜C12 へ。VREF の線を VM の線の隣に通さないため、上に出した。
  - IN2・IN1（2・3 番）は、下の口（行 8）から表の線で ESP32 へ。
- **C7〜C9**（VM − GND の 0.1µF）は、各ドライバの下で、PGND の母線と VM の母線の間に立てる（列 20・30・40）。**C10〜C12**（VREF − GND）は各ドライバの左上。
- **U4**（5V 電源）は左上。GND は専用の裸線で GND-STAR の島へ。**C13** は U4 の VIN と GND の足のすぐ下。**F2** のホルダは基板の外に出し、線の端を 2 か所（13,13 と 13,4）に付ける。
- **D3**（TVS）は C1 のすぐ右に寝かせる。**R1** は VM の母線の下（列 14）。R1 から先（電池電圧）は 100kΩ を通るので、細い線が何かに触れても 0.13mA しか流れない。

### 下の帯（行 15〜30）: 信号

- **ESP32** は右下。**アンテナを左、USB を右の辺**に向けて、ピンソケット2列（行 18 と行 28）に挿す。
  - USB は書き込みとログで何度も挿すので、右の辺に出す。**JP1** はその右下（46,30）。USB を挿す前に外すことを、場所で思い出せる。
  - アンテナの端（左）には、母線・端子台・電解コンデンサを近づけない。細い信号線がアンテナの下を通るのはよい（仮組みのブレッドボードも、中に金属の板ばねが並んでいたが DualSense はつながった）。
  - **ESP32 の足と、手順書の「左 n」「右 n」**: [stage3-procedure.md](../stage3-procedure.md) の「左 n」は、この基板では**下の列（行 28）の左から n 番目**（列 28+n）。「右 n」は**上の列（行 18）の左から n 番目**（列 28+n）。
  - ソケットで 8.5mm ほど浮くので、**ESP32 の下に線と低い部品（C6・R2）を通す**。どれも ESP32 を挿す前に付ける。
- **C6**（GPIO32 の 0.1µF）と **R2** は ESP32 の下。C6 は GPIO32（下の列の 7 番目）と GND（上の列の 7 番目）の間に、まっすぐ立てる（bom.md の「GPIO32 のすぐ近く」）。
- **エンコーダの口 J3・J6・J8** は下の辺に、左から輪0・輪1・輪2。端子台の並びは左から 青・黒・黄・緑。
  - **R10〜R15（保護抵抗）は端子台のすぐ上に立てる**（bom.md は「ESP32 の近く」だった。下の「bom.md から変えた所」）。
  - TP5・TP8・TP9（青 = 3.3V）は各端子台の左上。
  - 黒（SGND）は、真上の行 22 の SGND の線へ。
- **U6**（レベル変換）は ESP32 の左上（列 17〜23）。**切り欠きを左に**して 14 ピンのソケットに挿す（1 番が左下）。SGND につなぐ足を囲む裸線が U6 のまわりを回る。
- **VR1**（机上のつまみ）は U6 の左下（列 12）。足の形が合わなければ、3 本の線で基板の外に出す。
- **LED の口 J10** は左の辺（行 16〜20）。上から 5V・DIN・GND（LED のテープの並びと同じ）。C15・R16 はそのすぐ右。
  5V と GND は、U4 と GND-STAR から専用の2本（W04・W05）をより合わせて引く（bom.md のとおり）。
- **NT1**（GND-STAR と SGND をつなぐ1本）は被覆つきの線で、GND-STAR の島（6,7）から ESP32 の GND へ行く SGND の線（25,17）へ。**半田付けの最後に付ける**（その前に PGND と SGND が鳴らないことを確かめるため）。

### GND の分け方

```
 電池の − ─ J9 ─(母線 行10)─ C1 の − ＝ GND-STAR の島（列 7、行 6〜10）
                                 ├─ PGND の母線（行 10）→ U1〜U3 の GND・RS、C7〜C12、D3、C2
                                 ├─ U4 の GND（専用の裸線）
                                 ├─ W05 → J10 の GND（LED の電流）
                                 ├─ TP-G（測る点）
                                 └─ NT1 ──→ SGND（ESP32 の GND、エンコーダの黒、U6、VR1、R2・C6、TP-S）
```

- PGND と SGND がつながるのは NT1 だけ（スクリプトで確かめた）。
- ESP32 の上の列の GND 2本（1 番目と 7 番目）は、ESP32 の下の裸線（行 20）でもつなぐ。ESP32 を抜いても、R2・C6 の GND が SGND に残る。
  下の列の GND（14 番目）は基板の上では何にもつながない（ESP32 のボードの中で GND につながる）。
- 隣り合う穴に PGND と SGND が来る所は無い（同じく確かめた）。
- **TP-G・TP-S**（測る点）を足した。回路図には描かない。どちらも同じネットの別の点に立てるピンで、回路は変わらない。TP-G は「C1 の − 足」の代わりに黒い棒を当てる所（C1 の缶の下の足は当てにくい）。TP-S は SGND を測る所。

## 抜き差しできるようにするか

| 部品 | 付け方 | 理由 |
|---|---|---|
| ESP32（U5） | **ピンソケット 1×19 を2列**（1×20 を切る。高さ 8.5mm 程度） | 手順書の段 0〜1 で ESP32 を抜いて電圧を測る。予備がある。38 本を半田で外すのは難しい。**電池電圧の係数（H-1）は、この ESP32 と R1・R2 の組み合わせのもの**なので、同じ ESP32 を抜き差しして使い続ける。下に線を通せる |
| ドライバ U1〜U3 | **丸ピンのソケット（シングル）を 8 ピンに切って3本** | 付属の細ピン（0.5mm 角）は、普通のピンソケット（0.64mm 角用）では緩い。丸ピンのソケットならぴったり挿さる。段 0・3 で抜く。過電流でいちばん壊れやすい部品なので、取り替えられるようにする |
| U6（SN74AHCT125N） | **14 ピンの IC ソケット** | 段 8-0・8-1 で抜く |
| U4（BP5293-50） | **直付け** | 抜く手順が無い。足の並びを間違えると壊れる部品を、毎回挿し直すより、一度確かめて付けるほうが安全。足は3本なので取り替えも楽。5V の道に、振動で緩む接点を増やさない |
| JP1 | 2 ピンのピンヘッダとジャンパピン | USB を挿すたびに外す |
| TP | ピンヘッダを 1 本ずつ | ミノムシクリップを掛けられる |

- **ドライバのソケットを流れる電流**: モータの電流（ふだん 1輪 1A 前後と見積もり、ストール 2.3A はロック保護で 1 秒以内に止める）が、VM・GND・OUT の接点を通る。
  丸ピンのソケットを買うときに定格電流の表示を見て、3A 以上を選ぶ。03 で床を走らせたあと、ソケットに指を近づけて熱くないかを確かめる。熱ければ、そのドライバは直付けに変える。

## 線の太さ

| どこ | 流れる電流（最大） | 線 |
|---|---|---|
| 電池 → F1 → SW1 → J9（基板の外） | 7.5A | 14AWG のより線（手元。bom.md のとおり） |
| 母線（PGND 行 10、VM 行 12）と GND-STAR の島 | 7.5A（3輪のストール。ふだんは 3〜4A） | **裸のすずめっき線 φ1.0**（φ0.8 でも可）。通る穴すべてにはんだ付け |
| ドライバの足 → 母線・端子台（OUT・GND・RS・VM の短い線） | 2.3A | 裸のすずめっき線 φ0.8 |
| VM の渡り線 W01〜W03（10mm） | 2.3A | 被覆つき単線の、手元でいちばん太いもの |
| 5V と LED の GND（W04〜W07）、NT1 | 0.8A（LED 8個と ESP32。異常時は U4 の制限 1.9A まで） | 被覆つき AWG22 |
| 信号と 3V3（W08〜W30） | 数 mA | 被覆つき AWG24（AWG22 でもよい） |
| 隣の穴どうし、部品の足から口まで（5V・U4 の入力・GND-STAR への枝を含む） | 1A 前後まで（U4 の 5V の口は 0.8A。U4 の電流の制限が働くまでの間は 1.9A まで） | 部品の足の切れ端か、すずめっき線 φ0.5〜0.6。長さはどれも 2cm 未満 |

- **母線を 14AWG にしなかった理由**（bom.md は「基板の母線は 14AWG」だった）: 14AWG のより線は 1.0mm の穴に入らない。ランドに沿わせてはんだ付けするのも難しい。φ1.0 で足りる（下の計算）。基板の外の幹線は 14AWG のまま。
- **計算**（φ1.0 は断面 0.79mm²、抵抗 0.022Ω/m。φ0.8 は 0.50mm²、0.034Ω/m）:
  - 電圧降下: J9 から U3 まで約 9cm。7.5A でも 15mV 未満で、TP6 と TP1 の差 0.2V の目安に入る。
  - 発熱（ふだん）: 4A で 0.35W/m。裸線でも上がるのは 10℃ 未満。
  - 発熱（ストール）: 7.5A で 1.2W/m。ロック保護が 1 秒以内に止め、その間に上がる温度は 1℃未満。
  - ドライバの足からの線（φ0.8）: 2.3A で 0.18W/m、長さは 1cm 前後。
  - 5V の線 W07（AWG22、185mm）: 0.3A で 3mV。LED の線 W04・W05: 0.8A で 3mV ずつ。
  - 細い裸線 φ0.5（0.196mm²、0.088Ω/m）: 5V の口の 0.8A で 0.06W/m、U4 の制限までの 1.9A でも 0.32W/m。長さは 2cm 未満なので熱くならない。
- 手元のすずめっき線が細いとき（φ0.5 など）: 母線だけ φ1.0 を買う。φ0.5 の母線は、ふだんの 4A で数十℃上がる見積もりになり、余裕が無い。

## 表の線・裏の線・はんだの橋の使い分け

- **裏（はんだ面）の裸の線**: 同じネットを、行か列に沿ってまっすぐつなぐ所。母線、部品の足から口まで、SGND・3V3 の線。通る穴はすべてはんだ付けする（図の線が通る穴 = はんだを付ける穴）。曲がり角は穴の上で曲げる。
- **表（部品面）の被覆つきの線**: 別のネットの上を越える所、長い所、ESP32 の下。[wires.md](./wires.md) の W01〜W30 と NT1。両端は、つなぐ足のすぐ隣の穴に通し、裏で裸の線とはんだ付けする。
- **はんだの橋（隣の穴をはんだだけでつなぐ）は作らない。** 隣の穴どうしも、部品の足の切れ端か裸線の短い切れ端を寝かせてはんだ付けする。
  はんだだけの橋は割れやすい。付けたつもりの橋と、うっかりできた橋の見分けもつかない。「はんだだけの橋は全部まちがい」と決めておけば、裏を見てすぐ分かる。
- 隣り合う穴に別のネットが来る所は、スクリプトで調べた。12V（VM・モータの出力）の隣に別の線が来る所、5V の隣に ESP32 の GPIO につながる線が来る所、PGND の隣に SGND が来る所は無い。
  ほかに隣り合う所が 21 か所ある（信号どうしと、信号と SGND。ESP32 や U6 の足のそばの口）。どれも足どうしの間隔と同じ 2.54mm で、半田付けのあとにテスターで確かめる（[procedure.md](./procedure.md) の工程 5）。

## 外とつなぐ口の向きと並び

| 辺 | 口 | 並び（左から・上から） | 線の入る向き |
|---|---|---|---|
| 上 | J2（輪0）・J5（輪1）・J7（輪2）モータ | 各 1 = 赤、2 = 白（左が赤） | 上へ |
| 下 | J3（輪0）・J6（輪1）・J8（輪2）エンコーダ | 各 青・黒・黄・緑 | 下へ |
| 左 | J9 電源（10A） | **上が −（PGND）、下が +（VM）** | 左へ |
| 左 | J10 LED | 上から 5V・DIN・GND | 左へ |
| 右 | ESP32 の USB、JP1（右下） | — | 右へ |

- モータ（2P）とエンコーダ（4P）を反対の辺に置いた（bom.md の保護の表のとおり）。挿し間違えに、形と場所の両方で気づける。モータの PWM の線とエンコーダの線も離れる。
- **J9 の + と − は、上が −、下が +。** 母線の並び（PGND が上）に合わせた。逆にねじ留めすると、D3 が順方向に流れて電源をほぼ短絡する。
  安定化電源なら電流が制限に張り付き（TP1 は −1V 前後）、電池なら F1 が切れる。C1 も逆向きの電圧を受ける。
  基板の J9 の横に油性ペンで「上 − / 下 +」と書く。初めて電源を入れるときは安定化電源 0.2A で、電流と TP1 を見る（[procedure.md](./procedure.md) の工程 1）。
- J9（2P、太い）と J10（3P）は同じ左の辺にある。形と大きさが違うので見分けられる。それでも LED の線をつなぐときは J10 の横の印を確かめる。
- 輪0〜輪2 を、上の辺も下の辺も左から同じ順にした。モータとエンコーダの輪の取り違えを防ぐ。
- 電池からの線（14AWG）は J9 に入る。基板の外には J1（XT60）→ F1 → SW1 → J9 と並ぶ。SW1 の場所は 03 で決める。

## 取り付け穴と、ロボットへの付け方

- 板の四隅の取付穴（無ければ φ3.2 をあける）に M3 のねじと、**高さ 10mm 以上のスペーサ**（手元）で土台から浮かせる。配置は四隅を空けてある。
- **裏はむき出しの 12V の母線**。金属の板の上に直に置かない。土台が金属なら、間に絶縁の板を挟む。
- 基板の場所と向きは 03 で決める（持ち主）。決めるときに守ること:
  - 上の辺（モータの口）を、3輪の線がまとまる側へ向ける。下の辺（エンコーダの口）にも線が届くようにする。モータとエンコーダの線は同じ束で来るので、基板の手前で分ける。
  - 右の辺の USB と JP1 に手が届く。左の辺の J9・J10 にねじ回しが入る。
  - ESP32 のアンテナ（左の端）のまわりに金属（電池、モータ、金属の柱）を近づけない。
  - ドライバの上は 10mm 以上空ける（熱を逃がす）。
- F2 のホルダは基板の縁に結束バンドで留める。線の束は基板の縁で結束バンドで留め、端子台に引っぱる力がかからないようにする。

## 熱くなる部品

- **ドライバ U1〜U3**: 立てて、両面を空気に当てる。25.4mm おきで、モジュールどうしのすきまは約 4mm。
  ふだん 1A で約 0.6W。ストール 2.3A を流し続けると 3.2W で許容損失を超えるので、ファームのロック保護で止める（circuit.md §4）。
- **U4**: 立てて、ほかの熱い物から離した左上に置く。5V 0.7A を出すと数百 mW。
- **電解コンデンサ C1・C2・C15**: 熱で寿命が縮むので、熱い物から離す。C2 は U3 のモジュールの右端から約 2mm だが、熱が出る IC はモジュールのまん中にあり、C2 から約 12mm 離れる。
- **ESP32**: ボードの上の 3.3V レギュレータが約 0.5W（circuit.md §1）。ESP32 の下は低い部品（C6・R2）と線だけで、熱い物は置かない。
- 母線と線は「線の太さ」の計算のとおり、ふだん 10℃ 未満しか上がらない。
- 熱さは stage3-procedure.md の段 4・5 で指を近づけて確かめる。基板にしてからは、ドライバのソケットとその足の線も見る。

## 配置図の作り方

**穴の座標をスクリプト（[layout.mjs](./layout.mjs)）に書き、図と配線表を書き出し、回路図のネットリストと照らし合わせる。**

- 理由:
  - つながりを機械で確かめられる。調べるのは、回路図と同じつながりか（抜け・短絡）、PGND と SGND が NT1 だけでつながるか、12V の線の隣に別の線が来ないか、部品どうしが重ならないか、線の端を上から挿せるか。持ち主が図を細かく検証できない前提なので、目だけに頼らない。
  - 図を 1:1 で印刷して基板に重ねられる。はんだ面の図は左右を反対にしてあるので、裏返した基板にそのまま重なる。
  - 板の穴の数や部品の大きさが違ったら、座標を直して流し直すだけで、図・配線表・検査がそろって新しくなる。
- 採らなかった方法:
  - 方眼紙に手で描く、表計算で描く: まちがいを見つける手段が目しかない。
  - 専用のソフト（Fritzing、DIY Layout Creator、VeroRoute など）: 入れて使い方を覚える手間がかかる。回路図と照らすには、KiCad からつながりを持ち込む作業が別に要る。
- 使い方:
  - `node layout.mjs` で図と配線表を書き出し、検査の結果を表示する。誤りがあれば終了コード 1。
  - `node layout.mjs --adj` で、隣り合う別のネットの場所を全部表示する。
  - **回路図を直したら**、KiCad のネットリスト（kicadsexpr 形式）を書き出し、`node layout.mjs --import <.net のパス>` で nets.json を作り直す。それから検査を流し直す。

### 検査の結果（2026-11-20）

- 誤り 0 件、注意 0 件。部品 52（足 168 本。ESP32 の 38 本と TP-G・TP-S を含む）、裏の線 118 本、表の線 30 本と NT1、使う穴 474。
- 回路図の 59 本のネット（つながない足の 21 本を含む）と一致した。基板の外の J1・F1・SW1・M0〜M2・C3〜C5 は除いた。
  ESP32 の GND の3本は ESP32 のボードの中でもつながっているが、それに頼らずに基板の上だけでつながることも確かめた（頼ってよいのは、何にもつながない下の列の GND だけ）。
