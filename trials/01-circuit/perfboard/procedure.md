工程 0〜6 で基板を作り、工程 7 で stage3-procedure.md の段 0〜8 をこの基板で行う。

- 道具・比べ測りは [stage2-procedure.md](../stage2-procedure.md) と同じ

## いつも守ること

1. **電源（安定化電源・USB）をつないだまま半田付けしない。**
2. 半田付けのあと、電源を入れる前に、裏を明るい所で見る。
   - **はんだだけの橋**（隣の穴とはんだだけでつながっている所）は、全部まちがい（[plan.md](./plan.md) の「使い分け」）。吸い取り線で取る。
   - **いもはんだ**（丸く盛り上がって、穴やランドになじんでいない所）は、こてを当て直す。
   - 母線とすずめっき線は、図で線が通る穴すべてにはんだが付いているか。
3. 電源を入れる前に、TP1（VM）− TP-G（PGND）が鳴り続けないこと（C1・C2 の充電で一瞬鳴るのはよい）。
4. 電源は安定化電源の **12.0V・0.2A** から。出力を入れたら、まず電流を見る。**0.2A に張り付いたらすぐ切る。**
5. 12V を切ったら、放電用の抵抗（1kΩ）を **TP1 と TP-G** に 10 秒当て、TP1 が 1V 以下になったことを測ってから触る。
6. 黒い棒を当てる所: stage3-procedure.md の「C1 の − 足」は **TP-G**（7,6）、「ESP32 の GND」は **TP-S**（27,17）。
7. 仮組みから移す **R1・R2・ESP32 は、仮組みと同じものを使う**（電池電圧の係数 H-1 はこの組み合わせのもの）。抜くとき足を切らない。
8. こて先: 母線・端子台・C1・C2 の足は太いこて先、ESP32 と U6 のソケットのまわりは細いこて先。温度は、使うはんだの袋の目安に合わせる。

- [ ] TP1（7,14）と、VM の母線からの短い線（7,12 → 7,14）。
- [ ] VM の母線からの短い線をあと 2 本: 13,12 → 13,13（F2 の口）、14,12 → 14,14（R1 の口）。部品はまだ付けない。

**調べる**（電源なし）

- [ ] TP1 − TP-G: 一瞬鳴って止まる。鳴り続けたら短絡。
- [ ] C1・C2 の帯が上、D3 の帯が下。
- [ ] J9 の上のねじ − TP-G が鳴る。J9 の下のねじ − TP1 が鳴る。
- [ ] 電池側の線: XT60 の + の端子 − J9 の下のねじに入れる線の先が鳴る（SW1 があれば入れて）。XT60 の − − 上のねじの線の先が鳴る。確かめてから J9 にねじ留めする。

**電源を入れる**

- [ ] 安定化電源を 12.0V・0.2A に合わせ、XT60 につないで出力を入れる。電流がほぼ 0（0.01A 未満）。

- [ ] TP1（黒い棒は TP-G）が 12.0V（電源の表示と比べる）。

**合格**: 電流が張り付かない。TP1 が電源の表示と合う。熱いもの・におうものが無い。

**記録**: 電流、TP1。

- 12V を切り、放電用の抵抗を TP1 と TP-G に当てる。C1・C2 の放電の道がまだ無いので、当てないと何時間も残る。

## 工程 6. NT1 を付ける（最後の半田付け）

**付ける**

## 工程 7. 部品を挿して確かめる（stage3-procedure.md の段 0〜8）

[stage3-procedure.md](../stage3-procedure.md) の段 0〜8 を、この基板で順に行う。電流制限は手順書のまま（最大 1.0A。LiPo は 03）。この基板で違う所:

- **段 0**: 0-1 で抜くものは、もう抜いてある（ESP32・ドライバ・U6 は挿していない）。「`VBAT_SENSE` の列から G32 への線」は無い（ESP32 を挿さなければつながらない）。
  - 0-3 の「NT1 を一度抜き」は工程 5 で済んでいる。あとでやり直すときは、NT1 の SGND の側の端（25,17）のはんだを外して測り、付け直す。
  - 0-3 の「SW1・F2・C13・J9」の行を行う（基板で入れた）。
- **段 1**: ESP32 を挿さずに行う（工程 6 で測った値と同じになる）。
- **段 2**: 12V を切って USB も抜いた状態で、**ESP32 をアンテナを左（USB を右の辺）に向けて**ソケットに挿す。両方の列が全部の穴に入っているか、横から見る。
- **段 3**: ドライバを挿す。**1 番（GND）を左**にして、L 字のピンヘッダで立てる。印刷の GND・IN2・…・OUT2 がソケットの左から並ぶ。
- **段 4・5**: ドライバの熱さを確かめるとき、ソケットの足のまわりと、母線（裏）にも指を近づける。熱ければ止めて Claude に伝える。
- **段 7**: 7-2（ESP32 を 5V 電源から動かす）で JP1 を挿し、終わったら外す。
- **段 8**: U6 を挿す（**切り欠きを左**）。
- 黒い棒の「C1 の − 足」は TP-G、「ESP32 の GND」は TP-S。放電用の抵抗は TP1 と TP-G に当てる。

**終わったら**: notes.md の「記録」に書く（Claude に伝える）。基板の上で回路図と違う所があれば Claude に伝える（回路図か配置を直す）。
03 で床を走らせたあと、ドライバのソケットと U4 の熱さをもう一度確かめる（[plan.md](./plan.md) の「抜き差し」）。
