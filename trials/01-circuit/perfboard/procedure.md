# ユニバーサル基板の半田付けと、組み上がってからの確かめ方

[plan.md](./plan.md) の配置で、段階3の回路を 9×15cm の板1枚に移す手順。
**半田付けは一度に全部済ませ、組み上がった基板を確かめる**（持ち主、2026-11-20）。

確かめ方の考え方は [stage3-procedure.md](../stage3-procedure.md) と同じ。抜けるもの（ESP32・ドライバ・U6・モータとエンコーダの線・JP1）を抜いた状態で、まず電気を流さずに調べる。それから1つずつ挿しながら電源を入れる。
最後に、安定化電源でモータを回し（段 4〜6）、LiPo で浮かせて回す（段 9）。床に置いて走らせるのは 03。

- 道具・比べ測りは [stage2-procedure.md](../stage2-procedure.md) と同じ。プログラムの書き込み方は [firmware/README.md](../firmware/README.md)

## いつも守ること

1. **電源（安定化電源・USB・LiPo）をつないだまま半田付けしない。**
2. 電源を入れる前に、TP1（VM）− TP-G（PGND）が鳴り続けないこと（C1・C2 の充電で一瞬鳴って止まるのはよい）。
3. 安定化電源は手順の電流制限から。出力を入れたら、まず電流を見る。**張り付いたらすぐ切る。**
4. 12V を切ったら、放電用の抵抗（1kΩ）を **TP1 と TP-G** に 10 秒当て、TP1 が 1V 以下になったことを測ってから、挿す・抜く・触る。
5. 黒い棒を当てる所: 「C1 の − 足」（GND-STAR）は **TP-G**（7,6）、「ESP32 の GND」（SGND）は **TP-S**（27,17）。
   TP はピンが立っているので、テスターのミノムシクリップを掛けられる。回しながら測るときは、先にクリップを掛けておく。
6. **JP1 を挿すのは段 7-2 と段 9 だけ。USB を挿すときは必ず外す**（USB の 5V と U4 の 5V がぶつかる）。
7. **モータを安定化電源で回すのは、ESP32 を USB で動かしているときだけ**（電流制限で 12V が下がると、U4 から動いている ESP32 はリセットする）。
8. 切るときは 12V（LiPo なら SW1）が先、USB が後。
9. 部品の向き（挿すとき）: ESP32 は**アンテナを左**（USB を右の辺）、ドライバは **1 番（GND）を左**、U6 は**切り欠きを左**。
10. i_bench は、書き込み・リセット・USB の抜き挿しのあと輪0 に戻る。12V を入れる前に、表示の `wheel:` を見る。
11. SW1 を組んであれば、**SW1 を入れる前に ESP32 をリセットする**（USB をつないでいるあいだは、SW1 を切っても ESP32 が止まらず、切る前の指令が残る）。

## 準備（半田付けしない）

- [ ] 板が届いたら、**穴の数を数える**。行が 30 以上、列が 48 以上なら、この配置のまま使う（余りは右と下）。足りなければ止めて Claude に伝える（座標を直す）。
- [ ] 板の色を見る（緑ならガラスエポキシ。茶色・薄茶なら紙フェノールで、こてを当てる時間を短くする）。四隅の取付穴に M3 が通るか。
- [ ] [layout-top.svg](./layout-top.svg) と [layout-back.svg](./layout-back.svg) をブラウザで開いて印刷する。**倍率 100%**（「用紙に合わせる」を切る）。
  印刷した基板の外形の横幅を定規で測り、150mm（±1mm）であること。[wires.md](./wires.md) も印刷し、付けたものに印を付けていく。
- [ ] 部品面に油性ペンで書く:
  - 左上の穴の横に「1,1」、5 列・5 行ごとに番号
  - J9 の横に「上 − / 下 +」
  - J10 の横に「5V / DIN / GND」
  - 上の辺のモータの口に「輪0 輪1 輪2」、下の辺のエンコーダの口にも同じ
- [ ] 部品が穴に入るか試す（はんだ付けしない）: 端子台 4 種類、丸ピンのソケット、ピンソケット、F2 のホルダの線。入らない穴は φ1.3〜1.5mm のドリルで広げる。
- [ ] すずめっき線の太さを測る（母線は φ1.0、少なくとも φ0.8。[plan.md](./plan.md) の「線の太さ」）。
- [ ] 仮組みから部品を外し、部品番号を書いた袋に分ける。**R1・R2・ESP32 は仮組みと同じものを使う**（電池電圧の係数 H-1 はこの組み合わせのもの）。抜くとき足を切らない。
  モータとエンコーダの線には、輪の番号と色をテープで書く。
- [ ] 電池側の線を作る: J1（XT60）→ F1 → SW1 → J9 へ行く 14AWG。F1 のホルダの線が 1.25sq（16AWG）以上であることを見る（LiPo の前に要る）。
  SW1 がまだ無ければ、F1 から J9 へ直に（段 8 まではそれでよい。段 9 は SW1 が入るまで行わない）。

## 半田付け（一度に全部）

途中で電気は流さない。付ける順は、手間が少なく、向きの間違いに気づきやすい順。

1. [ ] **背の低い部品**: 抵抗（R1・R2・R10〜R17）、セラミックコンデンサ（C6〜C14）、D3、ESP32 の下の C6・R2。
   - **D3 は帯（カソード）を下**（11,14 の側）。
   - R10〜R15・R17 は立てて付ける。
2. [ ] **ソケットとピンヘッダ**:
   - ESP32 のピンソケット2列（行 18 と行 28、列 29〜47）。ESP32 を挿して位置を合わせ、両端の 4 本だけ仮に付ける。ESP32 を抜いてから残りを付ける。
   - ドライバの丸ピンのソケット3本（行 7。列 15〜22・25〜32・35〜42）。
   - U6 の IC ソケット（切り欠きを左。1 番は左下の 17,18）。
   - TP のピン 11 本と JP1 のピンヘッダ。
3. [ ] **U4**（9,4〜11,4）: **1 番（VIN）を右（11,4）に。** 印刷面の向きを、データシートの足の並びの図で確かめてから付ける。並びを間違えると壊れる。
4. [ ] **背の高い部品**: 端子台（J9・J2・J5・J7・J3・J6・J8・J10）、VR1（合わなければ 3 本の線で外へ）。
   **電解コンデンサ C1・C2・C15 は帯（−）の向きを図で確かめる**（C1・C2 は上、C15 は下）。逆だと破裂・発火する。
5. [ ] **裏の裸の線**（はんだ面の図）: 母線 2 本（PGND は行 10、VM は行 12、列 2〜46。φ1.0）→ ドライバの足の線（φ0.8）→ そのほかの細い線。
   - 母線の間の行 11 には何も付けない。
   - 線が通る穴はすべてはんだ付けする。部品の足を寝かせて使える所は使ってよい。
6. [ ] **表の被覆つきの線**（W01〜W30）。ESP32 の下を通る線（W18・W20〜W29）を先に、図の束の道のりに沿わせる。
   W04 と W05 はより合わせる。
7. [ ] **F2 のホルダ**: 線を 13,13 と 13,4 に付け、基板の縁に結束バンドで留める。ヒューズを入れる。
8. [ ] **NT1**（被覆つき AWG22）: GND-STAR の側の端（6,7）だけ付ける。**SGND の側の端（25,17）は付けずに残す**（段 0 で PGND と SGND がほかでつながっていないことを確かめるため）。
9. [ ] 電池側の線を J9 にねじ留めする。**+ が下のねじ、− が上のねじ。** ねじ留めする前に、XT60 の + の端子と + の線の先が鳴ることを確かめる。

**付け終わったら**（目で、明るい所で、裏を見る）

- [ ] **はんだだけの橋**（隣の穴とはんだだけでつながっている所）が無い。あれば全部まちがい（[plan.md](./plan.md) の「使い分け」）。吸い取り線で取る。
- [ ] **いもはんだ**（丸く盛り上がって、穴やランドになじんでいない所）が無い。あれば、こてを当て直す。
- [ ] 印刷した図と wires.md の全部に印が付いている（付け忘れが無い）。

## 1. 12V だけ（安定化電源 12.0V・0.2A。何も挿さない）

USB は挿さない。JP1 は外したまま。

- [ ] 安定化電源の出力を切ったまま 12.0V・0.2A に合わせ、XT60 につないで出力を入れる。電流がほぼ 0（0.02A 未満）。
  **0.2A に張り付いたらすぐ切る**（TP1 が −1V 前後なら J9 の + と − が逆で、D3 が順方向に流れている。そうでなければ C1・C2・C15・D3・U4 の向き）。

| 測る所 | 黒い棒 | 期待 |
|---|---|---|
| TP1 | TP-G | 12.0V（電源の表示と比べる） |
| TP6 | TP-G | TP1 との差が 0.1V 未満 |
| TP2 | TP-G | 4.75〜5.25V（比べ測り） |
| TP4 | TP-S | 約 2.16V。**3.3V 未満**（超えていたら ESP32 を挿さない） |
| ESP32 のソケットの下 7（G32） | TP-S | TP4 と同じ |
| ESP32 のソケットの下 19（5V） | TP-S | 0V（JP1 を外しているので） |
| TP3 | TP-S | 0V（ESP32 が無いので 3V3 は出ない） |
| U6 のソケットの 14 | U6 のソケットの 7 | 4.75〜5.25V |
| J10 の上のねじ | J10 の下のねじ | 4.75〜5.25V |
| 各ドライバのソケットの 5 | 同じソケットの 1 | 12V |
| TP7 | TP-S | ほぼ 0V |

- [ ] 1 分たったら U4 に指を近づける。何もつないでいないので温かくならない。

**合格**: 電流が張り付かない。表のとおり。熱いもの・におうものが無い。

**記録**: 電流、表の電圧。

- 12V を切り、放電用の抵抗を TP1 と TP-G に当てる。

## 2. ESP32 とエンコーダ（USB だけ。12V は使わない）

### 2-1 ESP32 を挿し、電圧を測る

- [ ] **ESP32 をアンテナを左（USB を右の辺）に向けて**ソケットに挿す。両方の列が全部の穴に入っているか、横から見る。
- [ ] USB を挿し、[i_bench](../firmware/i_bench/i_bench.ino) を書き込む。シリアルモニタを開く（115200 baud、行末は「改行」）。
  送る文字と表示の読み方は stage3-procedure.md の 2-1 の表。つまみを一度 0 に戻すと `準備よし`。
- [ ] つまみを左いっぱい → 右いっぱいと回し、`pot` が 0 から 100 まで変わる。時計回りで増えないときは VR1 の両端の線を入れ替える。つまみは 0 に戻す。
- [ ] TP3（黒い棒は TP-S）が 3.1〜3.5V（比べ測り）。
- [ ] TP5・TP8・TP9（黒い棒は TP-S）が、それぞれ 3.1〜3.5V。**12V に近ければすぐ USB を抜く。**

### 2-2 エンコーダの線をつなぎ、手で回して数える（3輪とも）

- [ ] USB を抜き、M0〜M2 のエンコーダの 4 本を J3・J6・J8 に（左から 青・黒・黄・緑。テープで輪を確かめる）。
  **モータの赤・白はまだどこにもつながず、先が何にも触れないようにする**（手で回すとモータが発電する）。
- [ ] USB を挿し、`r` を送る。どの軸も止めているあいだ、`count` の 3 つとも変わらない。
- [ ] 輪0（M0）: 出力軸に印を付け、`r` を送ってから**正転**（軸の側から見て時計回り）にちょうど 10 回転させる。`count` の 1 つ目を書き留める。3 回くり返す。
  回しているあいだ、2 つ目・3 つ目が変わらないこと。逆向きに回すと負になること。
- [ ] 輪1（M1、`count` の 2 つ目）、輪2（M2、3 つ目）も同じように。

**合格**: 止まっているあいだ数えない。10 回転の `count` が毎回ほぼ同じ（目安 8000〜8700）。回した輪の `count` だけが変わる。正転で `count` が増える（減った輪があれば、段 3 の前に Claude に伝える。`YELLOW_IS_A` を直す）。

**記録**: TP3、TP5・TP8・TP9、3 輪それぞれの 10 回転の `count`（3 回ぶん）。

## 3. ドライバを挿す（USB ＋ 安定化電源 0.5A。モータはまだつながない）

- [ ] 12V と USB を切った状態で、U1〜U3 を挿す。**1 番（GND）を左**にして、L 字のピンヘッダで立てる。印刷の GND・IN2・…・OUT2 がソケットの左から並ぶ。輪のテープを確かめる。
- [ ] テスター: TP1 − TP-G が鳴り続けない。
- [ ] USB を挿す（i_bench のまま）。つまみを 0 に戻して `準備よし`。表示が `wheel:0`。
- [ ] 安定化電源を **12.0V・0.5A** で入れる。電流がほぼ 0（0.1A 未満）。

| 測る所 | 黒い棒 | 期待 |
|---|---|---|
| TP1 | TP-G | 12.0V |
| TP6（U3 の VM） | TP-G | TP1 との差が 0.2V 未満 |
| TP7（U3 の GND） | TP-S | ほぼ 0V（0.1V 未満が目安） |

**テスターで出力を確かめる**（輪0 → 輪1 → 輪2 の順に。輪0 は J2、輪1 は J5、輪2 は J7。赤い棒を左のねじ、黒い棒を右のねじに当てる）

- [ ] `0`・`1`・`2` を送って輪を選ぶ（`wheel:` で確かめる）。つまみ 0 で **±10V を超えない**（出力が切れていると 0V 付近でふらつく。それは正常）。
- [ ] つまみをいちばん上まで上げる → **＋12V 付近**。0 に戻すと ±10V を超えなくなる。
- [ ] 0 に戻して 1 秒待ち、`b` を送り、いちばん上まで上げる → **−12V 付近**。0 に戻す。
- [ ] つまみを上げたまま `s` を送る → ±10V を超えなくなり、つまみを 0 に戻すまで出ない。
- [ ] 輪0 のときだけ: いちばん上にしたまま、J5・J7 にも棒を当て、**選んでいない輪に出ていない**（±10V を超えない）。

**合格**: 3 輪とも、0 で ±10V を超えない、いちばん上で前進 ＋12V 付近・後進 −12V 付近。選んでいない輪には出ない。電流が張り付かない。TP6・TP7 が表のとおり。

**記録**: 電流、TP1・TP6・TP7、3 輪の前進・後進のいちばん上での電圧。

- 切るときは 12V が先、USB が後。

## 4. モータを1個ずつつないで回す（安定化電源 0.5A → 1.0A）

輪0 → 輪1 → 輪2 の順に、1 個つなぐたびに次を行う。輪 n のモータは M n、端子台は J2（輪0）・J5（輪1）・J7（輪2）。

**つなぐ**（12V を切り、放電用の抵抗を当て、TP1 が 1V 以下、USB を抜いてから）

- [ ] 0.1µF（C3・C4・C5）がそのモータの端子（赤と白の間）にはんだ付けされている。
- [ ] モータの**赤を左のねじ（1）、白を右のねじ（2）**に。テープの輪の番号と合っている。
- [ ] モータを机の上で押さえ、タイヤが何にも触れずに回れるようにする（浮かせる）。
- [ ] テスター: つないだモータの 2 本のねじと、エンコーダの口のねじの間が鳴らない。

**指令を出していなければ回らない（0.5A）**

- [ ] USB を挿す（i_bench のまま）。つまみを 0 に戻し、その輪の番号（`0`・`1`・`2`）を送って `wheel:` を合わせる。
- [ ] 安定化電源を **12.0V・0.5A** で入れる。**どのモータも回らない**。電流がほぼ 0。

**つまみで回す（1.0A）**

- [ ] 電流制限を **1.0A** に上げる。
- [ ] つまみを 0 → いちばん上 → 0 とゆっくり往復させる。引っかかり・段付き・うなりが無いか見る。
  回っているとき、その輪の `count` が**増える**こと。**ほかの輪の `count` は変わらない**こと（モータの電流でカウントが乱れないか。基板では R10〜R15 を端子台の側に移したので、ここで確かめる）。
- [ ] いちばん上で数分回し、電流の幅を書き留める（段階2の M0 は 0.13〜0.15A）。そのドライバ、**ドライバのソケットの足のまわり**、裏の母線に指を近づけて熱を確かめる（触れないほど熱ければ止める）。
- [ ] つまみを 0 に戻して 1 秒待ち、`b` を送り、上げる → 逆に回り、その輪の `count` が**減る**。
- [ ] 回り始めの一瞬は 1.0A で頭打ちになってよい。**回っているあいだも 1.0A に張り付いたままなら止める。**

**合格**（3 輪とも）: 0 で止まっている。全域で滑らかに速さが変わる。前進でその輪の `count` が増え、後進で減る。ほかの輪の `count` は変わらない。熱くならない。電流が張り付かない。

**記録**: 輪ごとの電流の幅、熱、いちばん上での `cps`。

- 1 輪終わるたびに、12V が先、USB が後で切る。

## 5. 3輪を同じ強さで回す（i_bench。1.0A）

- [ ] テスターのクリップを TP1 と TP-G に掛けておく（直流電圧）。
- [ ] USB を挿す（i_bench のまま）。つまみを 0 にし、`a` を送る。`全部を選んだ` と出て、表示が `wheel:all`。
- [ ] 安定化電源を **12.0V・0.5A** で入れる。どのモータも回らない。電流制限を **1.0A** に上げる。
- [ ] つまみを半分くらいまでゆっくり上げる。**3 輪とも前進**し、`count` が 3 つとも増える。`cps` の 3 つの値を書き留める。
- [ ] つまみをいちばん上まで上げる。`cps` の 3 つの値と**電源の電流**を書き留める（目安 0.4〜0.5A）。回り始めの一瞬は 1.0A で頭打ちになってよい。
- [ ] いちばん上で回したまま測る（つまみから手を離してよい）。

  | 測る所 | 黒い棒 | 期待 |
  |---|---|---|
  | TP1 | TP-G | 電源の表示に近い |
  | TP6 | TP-G | TP1 との差が 0.2V 未満 |
  | TP7 | TP-S | ほぼ 0V（0.1V 未満が目安） |

- [ ] 数分回し、U1〜U3、ドライバのソケット、U4、C1・C2、裏の母線に指を近づけて熱を確かめる。
- [ ] つまみを 0 に戻して 1 秒待ち、`b` を送り、半分くらいまで上げる → 3 輪とも逆に回り、`count` が 3 つとも減る。つまみを 0 に戻す。

**合格**: 3 輪とも回る。`cps` の 3 つの差が 1 割くらいまで。電流が 1.0A に張り付かない。TP6・TP7 が表のとおり。熱くなるものが無い。

**記録**: 半分といちばん上での `cps`（3 輪）、いちばん上での電流、TP1・TP6・TP7、熱。

## 6. DualSense で回す（k_teleop。0.5A → 1.0A）

- [ ] 12V を切り、USB を挿したまま [k_teleop](../firmware/k_teleop/k_teleop.ino) を書き込む。シリアルモニタを開く。
  操作（L1 がデッドマン、左スティックの上下、十字キーの左右で 輪0 → 輪1 → 輪2 → 全部、上下で上限）と送る文字は、stage3-procedure.md の段 6 の説明のとおり。
- [ ] 安定化電源を **12.0V・0.5A** で入れる。DualSense の PS ボタンでつなぐ。ライトバーが緑になり、短く振動する。どのモータも回らない。
- [ ] スティックに触らずに `gap` のふだんの値を見る（**いつも 100ms を超えるなら止めて Claude に伝える**）。基板では ESP32 のアンテナの向きが変わったので、仮組みのときと比べる。

**1 輪ずつ・全部（1.0A）**

- [ ] 電流制限を **1.0A** に上げる。表示が `sel:0`。
- [ ] L1 を押していないとき、スティックを倒しても回らない。
- [ ] L1 を押しながらスティックを上に倒す → **M0 だけ**が前進し、`count` の 1 つ目が増える。L1 を離すとすぐ止まる。下に倒すと、止まるのを待ってから逆に回る。
- [ ] 十字キーの右で輪1・輪2 を選び、同じことを行う（**選んだ輪だけ**回る）。
- [ ] 十字キーの右で `全部` → L1 を押しながら倒す → 3 輪とも回る。
- [ ] どの輪でも `止めた: … 向きが逆` が出ない。

**止める仕組み（「全部」で回しながら）**

- [ ] L1 を離す → 3 輪ともすぐ止まる。
- [ ] `w` を送る → 3 輪ともすぐ止まり、`止めた: ウォッチドッグ`。スティックを中央に戻すまで回らない。
- [ ] `s` を送る → 3 輪ともすぐ止まる。スティックを中央に戻すまで回らない。
- [ ] DualSense の電源を切る（PS ボタンを約 10 秒）→ 3 輪ともすぐ止まり、`止めた: DualSense が切れた`。PS ボタンでつなぎ直せる。

**ロック保護（3 輪とも。段 9 の前に必ず）**

- [ ] 十字キーで輪0 を選ぶ。**M0 が止まっているときに**タイヤを手で押さえ、L1 を押してスティックをいっぱいに倒す
  → 約 1 秒で止まり、`止めた: 輪0 で、出しているのにエンコーダが回らない` と出て、DualSense が振動する。電流が 1.0A に張り付いたままにならない。
- [ ] 輪1・輪2 でも同じことをする。
- 回っているタイヤをつかんで止めない（軸のイモネジに指を挟む）。
- [ ] 終わったら、十字キーの下で上限を 30% に戻す。

**合格**: L1 を押していないと回らない。選んだ輪だけが回り、「全部」で 3 輪とも回る。止める仕組みのどれでも 3 輪ともすぐ止まり、スティックを中央に戻すまで回らない。ロック保護が 3 輪とも働く。

**記録**: `gap`（ふだんと最大）、ロック保護を試したときの電流、気になった動き。

- 切るときは 12V が先、USB が後。

## 7. 電池電圧を読む・ESP32 を 5V 電源から動かす・SW1（0.2A）

### 7-1 電池電圧の読み（USB ＋ 安定化電源）

- [ ] USB を挿し、[h_vbat](../firmware/h_vbat/h_vbat.ino) を書き込む。シリアルモニタを開く（115200 baud）。モータの GPIO には触らないプログラム。
- [ ] 安定化電源を **12.0V・0.2A** で入れる。数秒待って `pinmV` を読む。**12.0V で 2180〜2245**（段階2の H-1 では 2211）。
- [ ] 電源を 10.0V・12.6V にも変え、`pinmV` と電源の表示を書き留める（H-1 では 10.0V で 1845、12.6V で 2319）。
- [ ] `注意: 2.45V を超えている` が出たら、それ以上電圧を上げない。

**合格**: 電池の電圧 = 5.472 × `pinmV` ÷ 1000 − 0.090 が、電源の表示と ±0.05V 以内（R1・R2・ESP32 を仮組みから替えていなければ合う。替えたなら H-1 をやり直す）。

### 7-2 ESP32 を 5V 電源から動かす（安定化電源だけ）・SW1

- [ ] 12V を切り、**USB を抜く**。**モータの赤・白を 3 個とも外す**（5V 電源から動かしながら安定化電源で回すと、電流制限で 12V が下がって ESP32 がリセットするため）。
- [ ] **JP1 を挿す**。
- [ ] 安定化電源を **12.0V・0.2A** で入れる。電流が張り付かない（目安 0.1A 未満）。
- [ ] ESP32 の LED（GPIO2）が 0.5 秒ごとに点滅する（h_vbat が 5V 電源から動いている）。
- [ ] TP2（黒い棒は TP-G）が 4.75〜5.25V。TP3（黒い棒は TP-S）が 3.1〜3.5V。
- [ ] SW1 を組んであれば: SW1 を切る → 1〜2 秒で LED が止まり、電流が 0 になる。SW1 を入れる → LED がまた点滅する。
- [ ] 12V を切り、**JP1 を外す**。モータの赤・白を戻す。

**合格**: 電流が張り付かず、5V・3.3V が出て、ESP32 が動く。SW1 を切ると ESP32 も止まる。

**記録**: 7-1 の表（電源の表示、`pinmV`）、7-2 の電流、TP2、TP3、SW1 を切ってから LED が止まるまでの時間。

## 8. LED の口（U6 → 試験用の5個のテープ。0.2A → 0.5A）

J10・U6 のソケット・C15 の向きは段 0 と段 1 で確かめた。ここでは U6 を挿して確かめ、テープをつなぐ。手順の細かい所は stage3-procedure.md の 8-2・8-3 と同じ。

- **LED の付け外しは、12V と USB を両方切ってから。** 5V と GND を逆につなぐと LED が壊れる。J10 につなぐ LED は **8 個まで**。JP1 は外したまま。

### 8-1 U6 を挿して、3.3V が 5V になるかを見る（USB ＋ 安定化電源 12.0V・0.5A。LED はつながない）

- [ ] 12V も USB も切った状態で、U6（刻印に **AHCT**）を**切り欠きを左に**して挿す（逆に挿すと 5V と GND が入れ替わり、U6 が熱を持って壊れる）。
- [ ] USB を挿し、[l_led](../firmware/l_led/l_led.ino) を書き込む。表示に `v12:no`、`mode:level`。
- [ ] 12V を入れる前に、J10 のまん中 − 下のねじが 0V。
- [ ] 安定化電源を **12.0V・0.5A** で入れる。`12V が来た` と出て、1 秒後に `v12:yes`。電流が張り付かない。
- [ ] `h` を送る。J10 のまん中 − 下のねじが **4.5V 以上**。U6 のソケットの 2 − 7 が 3.0〜3.4V。
- [ ] `l` を送る。J10 のまん中 − 下のねじが **0.1V 以下**。
- [ ] 12V を切り、U6 に指を近づけて熱くない。

### 8-2 試験用の5個のテープをつなぐ（USB ＋ 安定化電源 12.0V・0.5A）

- [ ] 12V と USB を切り、放電用の抵抗を当てる。テープの**入力側**（`DIN` か `DI` と印刷された側）を J10 に: `5V` → 上のねじ、`DIN` → まん中、`GND` → 下のねじ。テスターで J10 の上のねじ ↔ テープの `5V`、下のねじ ↔ テープの `GND` が鳴る。
- [ ] USB を挿し、12.0V・0.5A で入れる。LED は消えたまま。
- [ ] `s` → `c`: J10 に近い LED から順に、**赤 → 緑 → 青** が 1 個ずつ点く。`r`・`g`・`b`・`w` で 5 個とも同じ色、`x` で全部消える。
- [ ] `w` のまま `+` で `bright:255` にする。電流が `x` のときより **0.1〜0.2A** 増える。J10 の上 − 下のねじが **4.75V 以上**。3 分たったら U4 に指を近づける（熱すぎない）。
- [ ] 点けたまま 12V を切る → 消える。入れ直すと 1 秒後にまた点く。`x` で消し、12V を切り、USB を抜く。

**合格**: `h` で 4.5V 以上、`l` で 0.1V 以下。5 個とも 3 色が順に点き、並びが J10 から順。電流の増え方が 0.1〜0.2A。U4・U6 が熱すぎない。

**記録**: J10 のまん中の `h`・`l` の電圧、`x`・`w` 255 の電流、`w` 255 での J10 の電圧、U4 の熱さ。

- 段 9 の前に、テープは外しておくか、つないだままでよい（k_teleop は LED を点けない。R17 で GPIO27 が L に保たれる）。

## 9. LiPo で浮かせて回す（k_teleop。JP1 を挿す。USB は挿さない）

ここからは**電流制限が無い**。止める仕組みは、ファーム（デッドマン、指令の途絶、ロック保護）と、F1・F2、SW1 だけになる。
床に置いて走らせるのは 03 で、ここでは浮かせて回すところまで。

**前提**（全部そろうまで LiPo をつながない）

- [ ] 段 6 のロック保護が **3 輪とも**働いた。
- [ ] F1（平形 10A。ホルダの線が 1.25sq 以上）、F2（平形 1A か 2A）が入っている。
- [ ] **SW1（DC24V 10A 以上の表示があるトグル）が J1〜J9 の間に入っていて、すぐ手が届く所にある。** SW1 が無ければ段 9 は行わない（非常停止の手段が無い）。
- [ ] LiPo を G3 の充電器でバランス充電してある。膨らみ・へこみ・傷が無い。テスターで XT60 の電圧が **11.1〜12.6V**。
- [ ] 電池を燃えない物の上（陶器の皿、金属のトレイ）に置く。段 9 のあいだはそばを離れない。
- [ ] 3 輪とも机に押さえて浮かせ、タイヤが何にも触れない。線がタイヤに巻き込まれない。
- [ ] k_teleop を書き込んである（段 6）。上限が 30%。

**準備**

- [ ] **USB を抜く**（LiPo のあいだはずっと挿さない。USB の 5V と U4 の 5V がぶつかるのと、PC を電池の大きな電流の回路につながないため）。
- [ ] **JP1 を挿す**（ESP32 は U4 から動く）。
- [ ] テスターのクリップを TP1 と TP-G に掛ける（直流電圧）。

**電源の入れ方（この順で）**

1. [ ] **SW1 を切る。**
2. [ ] **XT60 を挿す**（SW1 が切れているので、C1・C2 を充電する火花は XT60 ではなく SW1 の中で起きる。bom.md）。TP1 は 0V のまま（SW1 の後ろなので）。
3. [ ] スティックを中央にし、L1 から指を離して、**SW1 を入れる**。TP1 が電池の電圧（11.1〜12.6V）になる。ESP32 が起動する。どのモータも回らない。
   回り出したらすぐ SW1 を切る。
4. [ ] DualSense の PS ボタンでつなぐ。ライトバーが緑になる。

**回す**

- [ ] 輪0 を選び、L1 を押しながらスティックを上に倒す → M0 だけが前進する。L1 を離すとすぐ止まる。下に倒すと、止まるのを待ってから逆に回る。輪1・輪2 も同じ。
- [ ] `全部` を選び、いちばん倒して 3 輪を回す。回しているあいだの TP1 を読む（止まっているときとの差を書き留める。電池の中の抵抗と線で少し下がる）。
- [ ] 十字キーの上で上限を 10% ずつ上げ、50% と 100% で 3 輪を数秒ずつ回す。音・振動・におい、TP1 の下がりを見る。終わったら十字キーの下で上限を 30% に戻す。
- [ ] 数分回したら止め、U1〜U3、ドライバのソケットの足のまわり、U4、C1・C2、裏の母線、F1 のホルダに指を近づけて熱を確かめる。

**止める**

- [ ] L1 を離す → 3 輪ともすぐ止まる。
- [ ] DualSense の電源を切る（PS ボタンを約 10 秒）→ 3 輪ともすぐ止まる。つなぎ直す。
- [ ] 「全部」で回しながら **SW1 を切る**（非常停止の練習）→ 3 輪とも惰性で止まり、ESP32 も止まる。
  スティックを中央、L1 から指を離して SW1 を入れる → ESP32 が最初から起動し、DualSense をつなぎ直しても、スティックを中央に戻すまで回らない。

**ロック保護（輪0 だけ。片手を SW1 に置いて）**

- [ ] 輪0 を選ぶ。**M0 が止まっているときに**タイヤを手で押さえ、L1 を押してスティックをいっぱいに倒す
  → 約 1 秒で止まり、DualSense が振動する。**電流制限が無いので、約 2.3A が 1 秒ほど流れる。2 秒たっても止まらなければすぐ SW1 を切る。**
- 回っているタイヤをつかんで止めない。

**切り方**

- [ ] スティックを中央、L1 から指を離す → **SW1 を切る** → **XT60 を抜く**（しまうときは必ず抜く。bom.md）。
- [ ] TP1 が下がるまで待つか、放電用の抵抗を TP1 と TP-G に当てる。
- [ ] JP1 を外す（次に USB を挿す前に、必ず外す）。
- [ ] LiPo の電圧をテスターで測る。**11.1V（1 セル 3.7V）を下回ったら、その日は終えて充電する。** ファームの低電圧の保護はまだ無い（03 で入れる）ので、1 回は 10 分までにする。

**合格**: SW1 で入り、起動の直後に回らない。選んだ輪だけが回り、「全部」で 3 輪とも回る。上限 100% でも、におい・異音・熱すぎる所が無い。
L1 を離す・DualSense を切る・SW1 を切る、のどれでも止まり、SW1 を入れ直してもスティックを中央に戻すまで回らない。ロック保護が LiPo でも働く。

**記録**: LiPo の電圧（始める前・終わったあと）、止まっているときと 3 輪を回したとき（上限 30%・100%）の TP1、熱、気になった動き。

- **ここまで合格すれば、基板の確かめは終わり。** 床に置いて走らせるのは 03（[circuit-bringup.md](../../../docs/inherited/circuit-bringup.md) の「床に置いてからの確認」）。走らせたあと、ドライバのソケットの熱さをもう一度確かめる（[plan.md](./plan.md) の「抜き差し」）。

## 困ったとき

stage3-procedure.md の「困ったとき」に加えて:

| 起きたこと | 確かめること |
|---|---|
| 段 0 で TP-G − TP-S が鳴る | NT1 の端がまだ付いていないか確かめる。付いていなければ、どこかで PGND と SGND がつながっている。エンコーダの黒の列、U6 のまわりの線、W05 の端、J10 の下のねじのまわりを、裏から見て探す |
| 段 0 で ESP32 のソケットの穴が、つながらないはずの所と鳴る | その穴のまわりの裏（隣の口、ESP32 の下の線）にはんだの橋が無いか |
| 段 1 で電流が 0.2A に張り付く | すぐ切る。TP1 が −1V 前後なら J9 の + と − が逆。そうでなければ C1・C2・C15・D3 の向き、U4 の向き、母線の間（行 11）にはんだが流れていないか |
| 段 1 で TP2 が 5V にならない | U4 の向き（1 番が右）。F2 のヒューズ。U4 の GND の線が GND-STAR の島まで来ているか |
| 段 1 で TP4 が 3.3V を超える | R2 が付いているか、R2 の GND の側（列 35 の線と、上の列の GND 2 本をつなぐ線）。ESP32 を挿さない |
