## 回路図の決めごと

### 2026-11-06 段階の分け方

- **段階ごとに別の KiCad プロジェクトにする。** 前の段階の回路図をファイルごと残すため（trial-plan の「前の段階を上書きしない」）。
  プロジェクトが複数になってよいことは持ち主に確認済み。
  1つのプロジェクトに3段階を別シートで並べると、電源ネット（`VM` など）と部品番号（U1 など）が段階をまたいでつながり、ERC で段階ごとに確かめられない。
- 自作の部品記号は1つのライブラリにまとめ、全段階で共有する。同じ部品を段階ごとに作り直すと食い違いが入るため。
- ネット名は [circuit.md](../../docs/inherited/circuit.md) に合わせる（`BAT+`、`VM`、`PGND`、`SGND`、`+5V`、`+3V3`）。
  **ラベルで付ける。** 電源記号（値を書き換えるとネット名になることは確かめた）は、MCP ツールで置くと部品番号 `#PWR01` が図に出て隠せないので使わない。
- 部品の値が部品や線に重なるときは、Value を空（`~`）にして値を項目 `Spec` に入れ、図には値を書いた文字を別に置く。
  MCP ツールでは部品番号・値の文字の位置を選べないため。
- フットプリントは割り当てない（PCB を作らないため）。
- 自作の記号 JGB37-520 は、端子の間隔を2回変えた（赤と白の間に 0.1µF を縦に描ける 7.62mm、部品番号と値が端子名に重ならない位置）。
  端子の番号・名前・種類は最初から変えていない。

### 2026-11-06 3つの資料の食い違い（持ち主の OK 済み）

元にした資料: circuit.md、たたき台（schematic-draft.html）、Cirkit Designer の清書（途中まで）。

| 違い | 採ったもの | 理由 |
|---|---|---|
| 清書の ESP32 は ESP32-S3 の部品だった | classic ESP32（ESP32-WROOM-32） | 手元のものは刻印で classic と確認済み。S3 には GPIO23 も Bluetooth Classic も無い |
| 清書では ESP32 の GND がドライバの GND 端子につながっていた | GND-STAR へ専用の線（circuit.md どおり） | ドライバの GND 線にはモータ電流が流れ、ESP32 の 0V が揺れてエンコーダが数え間違える |
| 清書に JP1 が無い | 入れる | USB の 5V と BP5293-50 の 5V がぶつかって逆流する |
| 清書では SW1 をロッカースイッチ、TB1 を WAGO 221 ×2 にしていた | 段階1・2 では描かない。段階3で 03 と一緒に決める（清書の形が第一候補） | 机上は安定化電源の出力スイッチが主電源の代わり。1輪なら分岐が要らない。LiPo で使うならスイッチの直流定格 10A 以上を確かめる |
| 1000µF が清書では1個、文書では2個 | 段階2は入口の1個、段階3で2個目 | 1輪なら入口とドライバがほぼ同じ場所 |
| 清書ではエンコーダを黄→GPIO4、緑→GPIO13 と決めていた | 清書の線で描き、「A/B は E-6 で確定、逆ならファームで入れ替え」と注記 | PCNT は A/B をソフトで入れ替えられる |
| 清書のバッテリは 4000mAh 30C | 1500mAh 35C（hardware.md） | 手元にあるもの |
| 清書の 5V は汎用の3端子レギュレータ | BP5293-50 | 手元にあるもの。端子の並びはデータシートで確かめて描く |
| circuit.md で BP5293-50 の GND（1本）が動力側と信号側の両方に書かれている | 動力側として GND-STAR へ直接 | 1本しかないので、どちらかに決める必要がある |

### 2026-11-06 段階1の範囲（持ち主の OK 済み）

- ドライバは入れない。電源の入口（XT60・F1・C1）＋モータ1個の直結。E-1 ① と E-2 をこの回路で行う。
  - E-2 はドライバを通さない段。ESP32 が無いと IN1/IN2 を動かせない（内蔵のプルダウンで止まったまま）ので、ドライバを入れても確かめられることが無い。
  - 入口を段階1に入れるのは、段階2でもそのまま使う部分を、電流制限 0.2A で先に確かめるため。C1 を逆に付けていても、破裂する前に電流で気付ける。
- 逆接は XT60 の形で防ぐ（安定化電源も XT60 のケーブルでつなぐ）。逆接防止のダイオードは入れない（段階3で最大 約 7A 流れ、電圧降下と発熱が大きい）。
- モータの線は先がむき出しなので、ネジ式の端子台（J2）で付け外しできるようにする。E-2 で3個を付け替える・赤白を入れ替える、段階2の E-3 で LED 治具と差し替えるため。
  端子台は手元に無い。最初はブレッドボードで組むので、ユニバーサル基板に移るときに買う（5.08mm ピッチ、5A 以上）。
- 部品表: [kicad/stage1-motor/specs/bom.md](./kicad/stage1-motor/specs/bom.md)。bom-reviewer の承認と持ち主の OK 済み（2026-11-06）。
- F1 は車用の平形ヒューズ 10A。ホルダ（線付き）も手元にある。平形は 32V DC・遮断容量 1000A 前後の品が多く、LiPo の短絡にも向く。
  ホルダの定格電流（10A 以上か）は刻印で確かめる。

### 2026-11-07 最初はブレッドボードで組む

- 持ち主の回答: 最初はブレッドボードで組む。回路図は変えず、組み方だけ変える（詳しくは [bom.md の「ブレッドボードで組むとき」](./kicad/stage1-motor/specs/bom.md#ブレッドボードで組むとき)）。
- **E-2 の電流制限を 2.5A から 1.0A に下げた**（circuit-bringup.md は 2.5A）。ブレッドボードの接点の定格は製品によって 1A 前後〜3A で、
  2.5A のままだとモータの軸が止められたときや短絡したときに接点が熱を持ち、傷んだり樹脂が溶けたりする。
  E-2 で見るのは回る向きと無負荷電流だけなので 1.0A で足りる。ユニバーサル基板に移っても段階1は 1.0A のままでよい。
- J2（端子台）の代わりはブレッドボードの列。回路図の J2 は、ユニバーサル基板で組むときの形として残す。
- ブレッドボードの穴に入らない太い線と、ほつれるより線（モータの線）は、ピンヘッダのピンかジャンパ線をはんだ付けしてから挿す。

### 2026-11-10 段階2の進め方と部品表

- **組む順番**: 回路図は1輪ぶんの完成形を1枚に描き、組むときは一部ずつ足す。最初は ESP32 を USB だけで動かし（書き込み → つまみ → エンコーダ → DualSense）、
  そのあと 12V 側（5V 電源 → ドライバと LED 治具 → モータ → ESP32 を 5V 電源から）へ進む。表は [bom.md の「組む順番と電流制限」](./kicad/stage2-one-wheel/specs/bom.md#組む順番と電流制限)。
  - circuit-bringup.md は「全部組んでから 12V で少しずつ確かめる」順だが、USB だけの段を先にした。12V の問題とファームの問題を混ぜずに切り分けられ、
    配線を間違えても壊れるものがほとんど無いため。DualSense を早めに入れたのは、つながらなければ操作の方法から考え直すことになる、いちばん大きな未確認事項だから。
  - E-4 の電流制限は 1.5A から 1.0A に下げる（ブレッドボードの接点の定格に合わせる。段階1と同じ理由）。
- **ESP32 ボード**: 38ピンの classic ESP32 DevKitC 互換（ESP32-WROOM-32、USB シリアルは CP2102、3.3V は AMS1117）。写真で確認した。
  - 持ち主が挿していた緑の端子台の基板は、印刷が **ESP32-S3-DevKitC-1 のピン並び**（3.3, 3.3, RST, 4, 5, 6, 7, 15, … 46 …, 5V, G）で、このボードと合わない。
    名前どおりに配線すると 5V や GND が別の GPIO に入る。台が電源の端子どうしを中でつないでいれば USB を挿しただけでショートしうる。使わず、ブレッドボード2枚にまたがせる。
- **ドライバモジュールのピン**: 秋月の回路図で 1 GND、2 IN2、3 IN1、4 VREF、5 VM、6 OUT1、7 RS、8 OUT2（hardware.md の並びと同じ）。モジュール上に 0.1µF（GRM188F11H104Z）が2個ある。
- **BP5293-50**: 1 VIN、2 GND、3 VOUT。入出力のコンデンサは内蔵（ROHM データシート）。
- **接地**: `PGND` と `SGND` は NT1（ネットタイ）で `GND-STAR` の1点だけでつなぐ。
- **自作記号**: `ESP32-DevKitC-38`、`AE-TB67H450`、`BP5293-50` を足した。電源の入力側のピンは `passive`（PWR_FLAG を使わないため）。
  `JGB37-520` の pin4 を `power_in` から `passive` に変えた（段階2で `SGND` につなぐため）。段階1の回路図は記号の写しを持っているので変わらない。
- **分圧 100k / 27k**: classic ESP32 の ADC がまっすぐ読めるのは 約 2.45V まで。12.6V（2.68V）〜約 11.5V は不正確になるが、守りたい低い側は読めるので手元の抵抗のまま使う。
  → 2026-11-14 に **22k** に変えた（27k が手元に無かった。下の「分圧の R2」）。
- **手元の確認（持ち主の回答）**: 可変抵抗（10kΩ 程度）、LED 治具の部品（色違いの LED 2個、1kΩ）はある。ブレッドボードは十分ある。
- 部品表: [kicad/stage2-one-wheel/specs/bom.md](./kicad/stage2-one-wheel/specs/bom.md)。bom-reviewer は3回目で承認（2026-11-10）。持ち主が OK（2026-11-10）。
- **bom-reviewer の指摘で足したもの**:
  - D3（TVS P6KE18A、VM − PGND）。モータを逆転させると回生でエネルギーが電源へ戻るが、安定化電源は吸い込めないので VM が上がる
    （東芝のアプリケーションノートの Back-EMF の注意）。案B では逆転の指令で起きる。前進だけの E-3・E-4 では起きないので、E-6 の前に入れる。購入済み（2026-11-10）。
    - 持ち主の「必須か」の問いへの答え: 必須ではない。ファームが逆転の前に止めて（IN1・IN2 とも L で空転）待てば、逆起電力 約 11V は電源の 12V より低く、電源側へ戻らない。
      D3 はファームの誤り（全速から直接逆転など）への保険。無いと最悪の見積もりで U4 の上限 26V に届きうる。数十円で挿すだけなので入れる。
      LiPo につないだ後は電池が戻りの電流を吸うので、D3 が本当に効くのは主に安定化電源の間。
  - R10・R11（4.7kΩ、エンコーダの黄・緑と GPIO の間）。モータの赤・白を隣の列に挿し間違えたとき、GPIO に流れる電流を 約 1.9mA に抑える。手元にある（2026-11-10）。
  - U4 の入力ヒューズ F2（3A 以下）。ROHM のデータシートが「必ず」と書いている。机上は電源の制限 1.0A が代わりになるので、LiPo につなぐ前（段階3）に足す。
  - ESP32 を U4 から動かしたままモータを回さない（電流制限で VM が 5.8V まで下がり、U4 の UVLO 6.4V で ESP32 がリセットする）。モータは USB 給電のときだけ回す。

### 2026-11-14 抵抗の定格（1/8W でよいか）

- 持ち主の質問に答えた。R1・R2・R10・R11 は 1/8W（0.125W）でよい。どれも 20mW 以下で、1/8W の 15% 以下。
- **R9（LED 治具の 1kΩ）だけは 1/8W にしない。** 12.6V で 0.11W、1/8W の 90%（12.0V でも 80%）で、余裕の目安 70〜80% を超え、熱くなる。
  1/4W を使う。無ければ 1/8W の 2.2kΩ（0.05W、41%）。LED は約 4.5mA になるが、点いたかどうかは見える。
- R1・R2 は W ではなく **誤差 1%** が大事（電池電圧の読みの精度）。1/8W の抵抗は 5% のものが多いので、色の帯で確かめる（1% は帯が5本で、最後が茶）。
- 1/8W の抵抗は足が細く（約 0.4mm）、ブレッドボードで緩いことがある。触って抜けそうなら挿す穴を変える。

### 2026-11-14 分圧の R2 を 22kΩ に

- 27kΩ が手元に無く、22kΩ と 33kΩ がある（持ち主の回答）。**22kΩ にした。**
