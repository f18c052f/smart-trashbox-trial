# BOM: stage1-motor（段階1 モータ単体の動作確認）

計画: [trial-plan.md の 01 回路](../../../../../docs/trial-plan.md#01-回路)。元の資料: [circuit.md](../../../../../docs/inherited/circuit.md)、
[circuit-bringup.md](../../../../../docs/inherited/circuit-bringup.md)、[hardware.md](../../../../../docs/inherited/hardware.md)。

## 範囲

- この段階で確かめること: E-1 ①（電源の入口だけをつないで通電し、電流がほぼ 0 か）と E-2（ドライバを通さずにモータ1個を回す）。
- 入れないもの: ドライバ（AE-TB67H450）、ESP32、5V 電源（BP5293-50）、分圧、エンコーダの配線。これらは段階2で足す。
- 主電源スイッチ SW1・電源分岐端子 TB1 は描かない（段階3で 03 移動体と一緒に決める）。机上では安定化電源の出力スイッチが主電源の代わりになる。

## Constraints

- 入力: 机上は安定化電源 12.0V。電流制限は E-1 ① で 0.2A、E-2 で 1.0A（circuit-bringup.md の 2.5A から下げた。下の「ブレッドボードで組むとき」）。設計上の上限は LiPo 3S 満充電の 12.6V
- 電流: モータ1個。無負荷電流は E-2 で測る。ストール 約 2.3A（hardware.md）。安定化電源の電流制限で頭打ち。部品の定格は、circuit-bringup.md の 2.5A が流れても足りるように見積もる
- 基板: 最初はブレッドボード（持ち主の回答、2026-11-07）。そのあと秋月 C タイプ 72 × 47.5mm の片面のユニバーサル基板。**PCB は作らない**
- Layers / IPC class / Manufacturer min trace: 対象外（PCB を作らない）
- フットプリント: **割り当てない**（CLAUDE.md の決まり。ユニバーサル基板で組むため）
- Thermal: 室内、机上、ケースなし、自然空冷
- EMI/EMC: 規格の要求なし。モータのブラシノイズを C3 で発生源で抑える

ネット名 `BAT+`・`VM`・`PGND` は電源記号ではなく**ラベル**で付ける（部品ではないので表に載せない）。
最初は電源記号（`power:VCC` などの値を書き換える）にする予定だったが、配置計画の段階で次のことが分かったので変えた（2026-11-06）。

### 回路図での値の書き方

MCP ツールでは部品の文字（部品番号・値）の位置を選べず、値が部品や線に重なる。そのため F1・C1・TP1・J2・C3 は
**Value を空（`~`）にし、値は自作の項目 `Spec` に入れる（図には出ない）**。
F1・C1・J2・C3 は、図に値を書いた文字を部品のそばに別に置く。TP1 は `VM` の線から出ていて、測り方は注記 4 に書くので、値の文字は置かない。
J1（XT60M）と M0（JGB37-520）は重ならない位置に来るので Value をそのまま使う。

## 計算と根拠

- **C1 の耐圧**: 最大 12.6V（LiPo 満充電）÷ 35V = 36%。目安の 60〜80% を十分下回る。
- **C3 の耐圧**: 12.6V ÷ 50V = 25%。
- **C1 の充電電流（E-1 ①）**: 電流制限 0.2A で 1000µF を 12V まで充電する時間は 1000µF × 12V ÷ 0.2A = 60ms。
  電源を入れた直後に一瞬だけ制限に張り付き、その後ほぼ 0 に戻るのが正常。張り付いたままなら、短絡、C1 の逆付け、
  安定化電源用ケーブルの逆配線のどれかを疑い、すぐ切る。
- **F1 の定格**: 段階1の最大電流は 2.5A（電源の制限）で、10A には届かない。段階3のストール 2.3A × 3 ≒ 6.9A に対して 10A は 1.45 倍。
  hardware.md のとおり 5A では急加速で切れるおそれがあるので 10A のまま。
- **J2 の定格**: 段階1の最大は電源の制限 2.5A。12.6V でのストールでも 2.3A × 12.6 ÷ 12 ≒ 2.4A。
  5A 以上の端子台なら 50% 以下に収まる。基板用の一般的な端子台（2.54 / 3.5 / 5.0mm ピッチ）はたいてい 6A 以上ある。
- **電線**: 段階1は最大 2.5A。入口（J1 → F1 → C1 → J2）は段階3でも同じ線を使うので、hardware.md の 14AWG を使う。

## 保護

| 何から | どう守るか | 守らないもの・その理由 |
|---|---|---|
| 過電流・短絡（机上） | 安定化電源の電流制限（0.2A → 1.0A） | — |
| 短絡（LiPo につないだ後） | F1 10A | 段階1では LiPo を使わない |
| 逆接 | XT60 の形で逆に挿せない。安定化電源も XT60 のケーブルでつなぎ、ケーブルの安定化電源側の極性は使う前にテスターで確かめる。万一逆でも E-1 ① の 0.2A 制限で被害を抑える | 逆接防止のダイオード・MOSFET は入れない。段階3では最大 約 7A 流れ、ダイオードの電圧降下と発熱が大きい。形で防げるので部品を増やさない |
| サージ（TVS） | C1 1000µF が吸収 | 段階1ではモータを電源に直結しスイッチングが無い。電圧は C1 の耐圧 35V に比べて十分低い |
| モータのブラシノイズ | C3 をモータ端子に直付け | — |
| エンコーダの破損 | 4本を絶縁して基板に近づけない | 段階1では使わない。12V に触れると壊れる（hardware.md の注意） |

## ブレッドボードで組むとき

持ち主は最初にブレッドボードで組む（2026-11-07）。回路図はそのまま使い、組み方だけ次のようにする。

- **E-2 の電流制限を 1.0A に下げる**（circuit-bringup.md は 2.5A）。ブレッドボードの接点の定格は製品によって 1A 前後〜3A
  （例: 3M 製は 0.92A）。2.5A のままだと、モータの軸が止められたときや線どうしが触れたときに、定格を超える電流が接点に流れ続け、
  接点が熱を持って傷んだり周りの樹脂が溶けたりする。E-2 で見るのは回る向きと無負荷電流だけなので 1.0A で足りる。
  回り始めの一瞬は 1.0A で頭打ちになるが、軸に何も付けていなければ回り出す。回っている間も 1.0A に張り付いたままなら異常として止める。
- J2 の代わりはブレッドボードの列。モータの赤と白を、`VM` の列と `PGND` の列に挿す。
- ブレッドボードの穴に入らない線（XT60 から出す 14AWG、ヒューズホルダの線）や、より線（モータの線）は、そのまま挿さない。
  より線は先がほつれて隣の列に触れ、短絡するおそれがある。先にピンヘッダのピンかジャンパ線をはんだ付けし、つないだ所を熱収縮チューブかテープで覆う。
- C3 はブレッドボードでもモータ本体の端子に直付けのまま。

## F1 で確かめること

hardware.md には「10A ＋ ヒューズホルダ」としか書かれておらず、形と定格が分からない。現物の刻印を見て、次の4つを記録する。

| 項目 | 求めるもの | いつまでに |
|---|---|---|
| ヒューズの形 | ガラス管（5×20mm など）か、車用の平形か | 段階1で記録 |
| 定格電圧 | 12.6V 以上（直流の定格が書いてあればそれを見る） | 段階1で記録。ふつうのヒューズはこれを満たす |
| ホルダの定格電流 | 10A 以上。ヒューズより先にホルダが弱点にならないように | 段階1で記録 |
| 遮断容量（ヒューズが安全に切れる最大の電流） | LiPo の短絡電流（数百 A になりうる）を切れること | **LiPo につなぐ前（段階3）に必ず確かめる** |

- 段階1は安定化電源の電流制限（最大 2.5A）が先に効くので、遮断容量は関係しない。
- 車用の平形ヒューズは 32V DC・遮断容量 1000A 前後のものが多く、LiPo に向く。ガラス管の速断形は遮断容量が小さい（交流 250V で 100A 前後）ものが多いので、
  ガラス管だった場合は段階3までに平形への変更を考える。
