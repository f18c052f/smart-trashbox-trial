## 描く順番（schematic-design）

1. `set_page_size` で A3
2. Step 3 の部品を置く（`place_component`）。「そのあと」の欄がある部品は `move_component` で同じ x, y のまま回す
   （C・R・TP は 90 → 0、D3 は 0 → 270、U1・VR1 は 270 → 0、TP7 は 270 → 180）
3. Spec を入れる（`set_component_property`、key `Spec`）
4. W1〜W109 を `add_wires` で1回で引く。交点が27か所になることを確かめる
5. ラベル L1〜L37 を置く（`add_label`）
6. U5 の27本に未接続の印を付ける（`no_connect_pin`）
7. 文字 T1・V1〜V13・H1〜H5・N0〜N15 を置く（`add_text`）
8. `run_erc`（出力は一時フォルダ）。0件にする
9. ネットリストを書き出し、上の「試しに描いて確かめたこと」の表と同じになっているか確かめる
10. SVG に書き出し、文字の範囲が上の表と同じになっているか確かめる
