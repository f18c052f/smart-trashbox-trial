## 試しに描いて確かめたこと

この計画と同じ座標・回転・反転・値・文字・線・ラベル・未接続の印で、一時フォルダの別のプロジェクトに描いた（A3、同じ `mobile-base` ライブラリを登録）。本番のファイルには触れていない。

- 新しく使う記号（SW1・J9・4P 端子台・縦の F2・C2）の `get_pin_positions` は、下の「端子の位置」と一致した。
  - ほかのピンの位置は、記号のピンの位置（`get_symbol_info`）と回転・反転から計算した。
  - 計算した 171 本のピンのうち、未接続の印の19本を除く全部に線の端が来ている。
  - 線の端は、どれもピン・ラベル・ほかの線の端のどれかにある（浮いた端は無い）。
  - 線どうしが接続点なしに交わる所は無い。線がほかのピンの上を通る所も無い。
- `add_wires` で W1〜W205 を1回で引くと、下の「交点」の 47 か所に接続点が付いた。
- **ERC 0件**（文字を入れる前と後、TP6 を動かした後）。
- ネットリストは部品表のネットの表と同じ（名前のあるネット 35本。ほかは U5 の未接続の19本だけ）。
- 部品どうしの間隔: 53個の全部の組（1378組）で、横に 12.7mm 以上か縦に 10.16mm 以上離れている（部品の中心で計算）。1回目に指摘のあった TP6–C9 は横 15.24mm。
- パスコンと IC の距離（中心どうし）:
  - C7–U1・C8–U2・C9–U3: 16.26mm
  - C10–U1・C11–U2・C12–U3: 21.29mm
  - C13–U4: 20.67mm（どれも 25.4mm 以内）
  - C2 は U3 の中心から 35.56mm 離れているが、パスコンではなく `VM` の母線のための大きい電解。段階2の C1 と同じ扱い。U3 と同じ `VM`・`PGND` の線の左端に置き、「U3 の横」は輪2 の見出しと注記 5 で示す。
  - C6 は段階2と同じく分圧のまとまりにあり、ラベルで GPIO32 につながる（注記 16 で「GPIO32 の近く」）。
- 部品の外形どうしは触れない。SVG の文字は 400 個で、二重に描かれたものは無い。
- SVG で文字の範囲を測り、文字どうし、文字と線・部品の絵・未接続の印の距離を確かめた。0.6mm 未満の所は、下の「すき間の狭い所」に書いたものだけ。

## 描く順番（schematic-design）

段階3の図を 2026-11-15 に描いたときの順番と数（記録）。LED の口を足す順番は、下の「LED の口」の「描く順番」。

1. `set_page_size` で A3（`mobile-base.kicad_sch`。`sym-lib-table` は作成済み）
2. Step 3 の部品を置く（`place_component`）。「そのあと」の欄がある部品は、`move_component` で同じ x, y のまま回す
   - C・R・TP・F2・C13: 90 → 0
   - D3: 0 → 270
   - U1〜U3・VR1・C2: 270 → 0
