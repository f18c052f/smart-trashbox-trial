# 段階3 確認の手順（3輪ぶん。組み終えた回路を確かめる）

段階3の回路（3輪ぶん）は、すでに全部組んである（持ち主、2026-11-19）。この手順は、その回路を壊さずに確かめるためのもの。
**抜けるものを一度抜き、電気を流さずに確かめてから、1つずつ戻しながら電源を入れる。** 段 0 から 7 へ順に進む。
LED の口（WS2812B。2026-11-20 に回路図に足した）を組んだら、段 0〜7 に合格した回路に段 8 で足す。

- 回路図: [mobile-base.kicad_sch](./kicad/mobile-base/mobile-base.kicad_sch)
- 部品とつなぎ方の正: [bom.md](./kicad/mobile-base/specs/bom.md)
- プログラムの書き込み方: [firmware/README.md](./firmware/README.md)
- 元にした手順: [circuit-bringup.md](../../docs/inherited/circuit-bringup.md) の E-0〜E-7
- 段階2の手順書: [stage2-procedure.md](./stage2-procedure.md)。**道具・比べ測り・いつも守ること（1〜5）は段階2と同じ。** ここには段階3で増えること・変わることを書く。
- ユニバーサル基板へ移すことは、この手順書には入れない（回路を足すかもしれないため。持ち主、2026-11-19）。
  SW1・F2・C13・J9（ユニバーサル基板で入れる予定の部品）を組んであれば、その行も確かめる。組んでいなければ飛ばす。

**1つの段で戻すのは1つだけ。合格しなかったら次へ進まない。** 不合格も [notes.md](./notes.md) の「記録」に書く。
困ったら、その段で止めて Claude に、測った値と起きたことを伝える。

## 準備

### 増える道具

- **放電用の抵抗**: 1kΩ（1/4W）の両方の足にミノムシクリップを付けたもの。
  C1・C2（1000µF が2個）があるので、12V を切ってから TP1 が 1V 以下になるまで、待つだけだと **7 分ほど**かかる。
  12V を切ったあと、これを C1 の + 足と − 足に 10 秒当てると 1V 以下になる（12.6V でも 0.16W で、1/4W の 64%）。当てたあと、テスターで TP1 が 1V 以下になったことを確かめる。
- マスキングテープとペン。抜いた線に「輪0 赤」「輪1 エンコーダ」のように書いて貼る。戻すときに取り違えないため。

### 比べ測り（段階3で増える所）

段階2の手順書の「比べ測り」と同じやり方で測る。

| 段 | 測る所 | 比べるのに使う電源の電圧 |
|---|---|---|
| 1・7 | TP2（`+5V`） | 4.75V と 5.25V |
| 8 | J10-1 − J10-3（LED の 5V） | 4.75V と 5.25V |
| 1 | TP4（`VBAT_SENSE`） | 3.30V（これ未満） |
| 2・7 | TP3（3V3） | 3.10V と 3.50V |
| 2 | TP5・TP8・TP9（3輪のエンコーダの電源） | 3.10V と 3.50V |
| 3・5 | TP6（U3 の VM）と TP1 の差 | 比べなくてよい。TP1 と TP6 を同じテスター・同じレンジで続けて測り、テスターの値どうしの差を見る |

### いつも守ること（段階2の 1〜5 に足すこと）

6. **12V を切ったら、放電用の抵抗を当ててから TP1 を測る。** 待つだけだと 7 分ほどかかる。
7. **モータを回すのは ESP32 を USB で動かしているときだけ。** JP1 は外したまま（段 7 の②だけ挿す）。
   電流制限に当たって 12V が下がると、5V 電源から動いている ESP32 はリセットする（bom.md）。
8. i_bench は、書き込み・リセット・USB の抜き挿しのあと**輪0 に戻る**。12V を入れる前に、表示の `wheel:` が回したい輪になっていることを見る。
9. SW1 を組んであるとき: **SW1 を入れる前に ESP32 をリセットする**（基板の EN ボタン）。USB をつないでいるあいだは、SW1 を切っても ESP32 は止まらず、
   切る前に出していた指令が残る。そのまま SW1 を入れると、その瞬間に回り出す。

### 0-3 回路を調べる（テスター）

- [ ] J2・J5・J7 のどの列と、J3・J6・J8 のどの列の間でも鳴らない

**`PGND` と `SGND`**

## 2. ESP32 とエンコーダ（USB だけ。12V は使わない）

### 2-1 i_bench を書き込み、電圧を測る

- [ ] USB を挿し、[i_bench](./firmware/i_bench/i_bench.ino) を書き込む。シリアルモニタを開く（115200 baud、行末は「改行」）。i_bench は次のように動く。
  - 書き込み・リセットの直後は何も出さない。つまみを一度いちばん下（0）に戻すと `準備よし`。
  - 出すのは**選んだ輪だけ**。最初は輪0。シリアルモニタから送る文字:

    | 送る文字 | すること |
    |---|---|
    | `0` `1` `2` | 出す輪を選ぶ（輪0 = U1・M0、輪1 = U2・M1、輪2 = U3・M2）。選び直すと前進に戻る |
    | `a` | 3輪全部に同じ強さを出す（段 5 で使う） |
    | `f` `b` | 前進・後進にする |
    | `s` | すぐ止める。つまみを 0 に戻すまで出さない |
    | `r` | 3輪の `count` を 0 に戻す |

    輪を選ぶ・向きを変えるのは、つまみが 0 で、止まってから 1 秒たったときだけ受け付ける（早いと「変えない」と出る）。
  - 0.1 秒ごとに `wheel`（選んでいる輪）、`pot`（つまみ %）、`duty`（出している強さ %）、`count`（輪0/輪1/輪2 のエンコーダ）、`cps`（輪0/輪1/輪2 の 1 秒あたり）、`ready` を表示する。
- [ ] つまみを左いっぱい → 右いっぱいと回し、`pot` が 0 から 100 まで変わること。時計回りで増えないときは VR1 の両端の線を入れ替える。つまみは 0 に戻しておく。
- [ ] TP3: ESP32 の GND（黒）と 3V3（赤）の間が 3.1〜3.5V（比べ測り）。
- [ ] TP5・TP8・TP9: J3・J6・J8 の黒の列（黒い棒）と青の列（赤い棒）の間が、それぞれ約 3.3V（比べ測りで 3.10〜3.50V）。

### 2-2 エンコーダを戻し、手で回して数える（3輪とも）

- [ ] USB を抜き、M0〜M2 のエンコーダの4本を J3・J6・J8 に戻す（テープで輪を確かめる）。**モータの赤・白はまだどこにも挿さず、先が何にも触れないようにする**（手で回すとモータが発電する）。
- [ ] USB を挿し、`r` を送る。どの軸も止めているあいだ、`count` の3つとも変わらないこと。
- [ ] 輪0（M0）: 出力軸に印を付け、`r` を送ってから、**正転**（軸側から見て時計回り）にちょうど 10 回転させる。`count` の1つ目を書き留める。3回くり返す。
  回しているあいだ、2つ目・3つ目が変わらないこと。逆向きに回すと負になること。
- [ ] 輪1（M1、`count` の2つ目）、輪2（M2、3つ目）も同じように。

**合格**: 止まっているあいだ数えない。10 回転の `count` が毎回ほぼ同じ（目安 8000〜8700）。回した輪の `count` だけが変わる。

- 正転で `count` が**増えた**輪は黄が A相（プログラムはそのまま）。**減った**輪があれば、段 3 へ進む前に Claude に伝える
  （i_bench と k_teleop の `YELLOW_IS_A` のその輪を `false` に直して、書き込み直す）。

**記録**: TP3、TP5・TP8・TP9、`pot` の範囲、3輪それぞれの 10 回転の `count`（3回ぶん）と、正転で増えたか減ったか。

## 3. ドライバ U1〜U3 を戻す（USB ＋ 安定化電源 0.5A。モータはまだつながない）

**戻す**（12V を切り、TP1 が 1V 以下、USB を抜いてから）

- [ ] U1〜U3 を、モジュールの印刷で 1〜8 の名前を確かめて挿す（どの輪の場所か、テープで確かめる）。
- [ ] テスター: `VM` − `PGND` で鳴り続けない。

**電源を入れる**

- [ ] USB を挿す（i_bench のまま）。つまみを 0 に戻し、`準備よし` が出ることを見る。表示が `wheel:0`。
- [ ] 安定化電源を **12.0V・0.5A** に合わせ、出力を入れる。電流がほぼ 0（0.1A 未満）。

**測る**（E-1 ⑤。U3 の所）

| 測る所 | 黒い棒 | 期待 |
|---|---|---|
| TP1: C1 の + 足 | C1 の − 足 | 12.0V（電源の表示と比べる） |
| TP6: U3 の VM（5 番） | C1 の − 足 | TP1 との差が 0.2V 未満 |
| TP7: U3 の GND（1 番） | ESP32 の GND | ほぼ 0V（0.1V 未満が目安） |

**テスターで出力を確かめる**（E-3 の代わり。輪0 → 輪1 → 輪2 の順に）

輪0 は J2、輪1 は J5、輪2 は J7。テスターの赤い棒をその 1、黒い棒を 2 に当てる（直流電圧）。

- [ ] `0`・`1`・`2` を送って、確かめる輪を選ぶ（表示の `wheel:` で確かめる）。つまみ 0 で **±10V を超えない**（出力が切れていると 0V 付近でふらつく。それは正常）。
- [ ] つまみをいちばん上まで上げる → **＋12V 付近**。0 に戻すと ±10V を超えなくなる。
- [ ] 0 に戻して 1 秒待ち、`b` を送り、いちばん上まで上げる → **−12V 付近**。0 に戻す。
- [ ] つまみを上げたまま `s` を送る → ±10V を超えなくなり、つまみを 0 に戻すまで出ないこと。
- [ ] 輪0 を確かめるときだけ: つまみをいちばん上にしたまま、J5・J7 にも棒を当て、**選んでいない輪の出力が ±10V を超えない**こと（ほかの輪に出ていない）。

**合格**: 3輪とも、0 で ±10V を超えない、いちばん上で前進 ＋12V 付近・後進 −12V 付近。選んでいない輪には出ない。電流が張り付かない。TP6・TP7 が期待どおり。

## 4. モータを1個ずつ戻して回す（E-4。0.5A → 1.0A）

- [ ] モータを机の上で押さえ、タイヤが何にも触れずに回れるようにする（浮かせる）。
- [ ] テスター: 戻したモータの2列と、エンコーダの列（J3・J6・J8）の間でブザーが鳴らない。

**指令を出していなければ回らない（0.5A）**

- [ ] 回り始めの一瞬は 1.0A で頭打ちになってよい。**回っているあいだも 1.0A に張り付いたままなら止める。**

**合格**（3輪とも）: 0 で止まっている。全域で滑らかに速さが変わる。前進でその輪の `count` が増え、後進で減る。ほかの輪の `count` は変わらない。ドライバが触れないほど熱くならない。電流が張り付かない。

**記録**: 輪ごとの電流の幅、熱、いちばん上での `cps`。

- 1輪終わるたびに、12V が先、USB が後で切る。

## 6. DualSense で回す（k_teleop。E-5〜E-7。0.5A → 1.0A）

- [ ] 12V を切り、USB を挿したまま [k_teleop](./firmware/k_teleop/k_teleop.ino) を書き込む。シリアルモニタを開く（115200 baud、行末は「改行」）。
  段 2 で `YELLOW_IS_A` を直したなら、k_teleop も同じに直してあること（Claude が直す）。k_teleop は次のように動く。
  - **L1 を押しているあいだだけ動く**。左スティックの上下で前進・後進、倒した量で強さが変わる。いちばん倒して「上限」（最初 30%）。十字キーの上・下で上限を 10% ずつ変える。
  - **十字キーの右・左で回す輪を選ぶ**: 輪0 → 輪1 → 輪2 → 全部 → 輪0 …（最初は輪0）。選び直すと全部の輪をすぐ止め、
    スティックを中央に戻すまで出さない（DualSense が短く振動し、ライトバーが赤になる。中央に戻すと緑）。
  - 止める仕組み（L1 を離す、ウォッチドッグ、DualSense が切れる、ロック保護、向きの見張り、`s`）は、どれも**全部の輪**をすぐ止める。
    ロック保護と向きの見張りは輪ごとに見て、どの輪で止めたかを `止めた: 輪1 で、…` のように出す。
  - シリアルモニタから送る文字: `s` すぐ止める、`w` DualSense の値を 1 秒読まない（ウォッチドッグの試験）、`r` 3輪の `count` を 0 に戻す。
  - 0.1 秒ごとに `L1`、`stick`、`max`、`sel`（選んでいる輪。0・1・2・all）、`duty`・`count`・`cps`（輪0/輪1/輪2）、`gap`、`ready` を表示する。

**つなぐ（0.5A）**

- [ ] 安定化電源を **12.0V・0.5A** で入れる。DualSense の PS ボタンを押してつなぐ。ライトバーが緑になり、短く振動する。どのモータも回らない。
- [ ] スティックに触らずに、`gap` のふだんの値を見る（**いつも 100ms を超えるなら止めて Claude に伝える**）。

**1輪ずつ回す（1.0A）**

- [ ] 電流制限を **1.0A** に上げる。表示が `sel:0`。
- [ ] **L1 を押していないとき**、スティックを倒しても回らない。
- [ ] L1 を押しながらスティックを上に倒す → **M0 だけ**が前進し、`count` の1つ目が増える。2つ目・3つ目は変わらない。L1 を離すとすぐ止まる。
- [ ] スティックを下に倒す → `輪0 向きを変える: 止まるのを待つ` → `輪0 後進にした` と出てから逆に回る。
- [ ] 十字キーの右 → `選んだ: 輪1`。スティックを中央に戻してから、輪1 で同じことを行う。**M1 だけ**が回る。
- [ ] 十字キーの右 → `選んだ: 輪2`。同じことを輪2 で。**M2 だけ**が回る。
- [ ] 十字キーの右 → `選んだ: 全部`。L1 を押しながら倒す → 3輪とも回る。
- [ ] どの輪でも `止めた: … 向きが逆` が出ないこと（出たら、その輪の `YELLOW_IS_A` か、モータの赤・白の向き）。

**止める仕組み（「全部」で回しながら）**

- [ ] L1 を離す → 3輪ともすぐ止まる。もう一度押せばそのまま回る。
- [ ] `w` を送る → 3輪ともすぐ止まり、`止めた: ウォッチドッグ` と出る。スティックを中央に戻すまで回らない。
- [ ] `s` を送る → 3輪ともすぐ止まる。スティックを中央に戻すまで回らない。
- [ ] DualSense の電源を切る（PS ボタンを約 10 秒）→ 3輪ともすぐ止まり、`止めた: DualSense が切れた` と出る。PS ボタンでつなぎ直せる。

**ロック保護（3輪とも。LiPo の前に必ず確かめる）**

- [ ] 十字キーで輪0 を選ぶ。**M0 が止まっているときに**タイヤを手で押さえ、L1 を押してスティックをいっぱいに倒す
  → 約 1 秒で止まり、`止めた: 輪0 で、出しているのにエンコーダが回らない` と出て、DualSense が振動する。電流が 1.0A に張り付いたままにならない。
- [ ] 輪1・輪2 でも同じことをする。
- 回っているタイヤをつかんで止めない（軸のイモネジに指を挟む）。
- [ ] 終わったら、十字キーの下で上限を 30% に戻す。

**合格**: L1 を押していないと回らない。選んだ輪だけが回り、「全部」で3輪とも回る。選んでいない輪の `count` は変わらない。
L1 を離す・`w`・`s`・DualSense の電源を切る、のどれでも3輪ともすぐ止まり、スティックを中央に戻すまで回らない。ロック保護が3輪とも働く。

**記録**: `gap`（ふだんと最大）、遅れの感じ、ロック保護を試したときの電流、気になった動き。

- 切るときは 12V が先、USB が後。

## 8. LED の口を足す（WS2812B。0.2A → 0.5A）

段 0〜7 に合格した回路に、LED の口（U6・R17・C14・C15・R16・J10）を組み足してから行う。回路図の左下と、[bom.md の「LED の口」](./kicad/mobile-base/specs/bom.md)。

- U6 は **SN74AHCT125N**（刻印に **AHCT**）。T の無い AHC125 では LED が点かないか、点いたり点かなかったりする。
- U6 は **14 ピンの IC ソケット**に挿す形で組む（8-0・8-1 で抜いて調べるため）。直接はんだ付けしたなら、8-0 の U6 のソケットの行と 8-1 は飛ばす。
- JP1 は外したまま（ESP32 は USB から動かす。段 7 の②のあと外した）。
- **LED の付け外しは、12V と USB を両方切ってから。** 5V と GND を逆につなぐと LED が壊れる。J10 につなぐ LED は **8個まで**。

### 8-0 電気を流さずに調べる（電源・USB なし。U6 はソケットから抜く。LED はつながない）

テスターのブザー（導通）と抵抗のレンジで。U6 のソケットのピン番号は、切り欠き（1 ピンの印）を上にして上から見たとき、左の列が上から 1〜7、右の列が上から 14〜8（回路図の U6 と同じ並び）。

| 測る2点 | 合格 | 間違えていると |
|---|---|---|
| J10-1 ↔ TP2（`+5V`） | 鳴る | LED に 5V が来ない |
| J10-3 ↔ C1 の − 足（`GND-STAR`） | 鳴る | LED の電流の戻り道が無い |
| J10-1 ↔ J10-3 | 鳴らない（C15 で一瞬鳴ってすぐ止まるのはよい。抵抗のレンジで数 kΩ 以上へ上がっていく） | 5V の短絡。U4 が止まる |
| J10-2 ↔ J10-3 | 鳴らない | 信号が GND に落ちている |
| C15 の向き | 帯（−）が J10-3（`PGND`）の側 | **逆だと破裂する** |
| ソケット 14 ↔ TP2（`+5V`） | 鳴る | U6 に電源が来ない |
| ソケット 7 ↔ ESP32 の GND（左 14） | 鳴る | U6 の GND が浮く |
| ソケット 1・4・5・9・10・12・13 ↔ ソケット 7 | 7本とも鳴る | 使わない入力が浮く（U6 が熱を持つことがある） |

| ソケット 2 ↔ ESP32 の G27（左 11） | 鳴る | 信号が届かない |

| ソケット 3 ↔ J10-2 | 約 330Ω（R16） | — |
| ソケット 6・8・11 ↔ ソケット 7・14 | 鳴らない（どこにもつながない） | 使わない出力がぶつかる |

**合格**: 全部の行が合う。

### 8-2 U6 を挿して、3.3V が 5V になるかを見る（USB ＋ 安定化電源 12.0V・0.5A。LED はつながない）

- [ ] 12V も USB も切った状態で、U6 を**1 ピンの印（切り欠きか丸いくぼみ）がソケットの 1 ピン（回路図の U6 の左上）に来るように**挿す（逆に挿すと 5V と GND が入れ替わり、U6 が熱を持って壊れる）。

- [ ] `c` を送る。J10 に近い LED から順に、**赤 → 緑 → 青** が1個ずつ点いて、5個目のあと最初に戻る。
- [ ] `r`・`g`・`b`・`w` を送り、5個とも同じ色で点く。`x` で全部消える。
- [ ] `w` のまま `+` を何回か送り、`bright:255`（`est` が 約 305mA）にする。安定化電源の電流が、`x` のときより **0.1〜0.2A** 増える（5V × 0.305A ÷ 12.0V ÷ 効率 0.8 ≒ 0.16A）。
- [ ] そのまま J10-1 − J10-3 が **4.75V 以上**（テープの線で下がりすぎていない）。
- [ ] 3 分たったら U4（BP5293-50）を指で触る。温かいのはよい。熱くて手を離すほどなら、すぐ `x` で消して記録する。
- [ ] 点けたまま 12V を切る。LED が消え、`12V が無い` と出る。12V を入れ直すと、1 秒後にまた点く。
- [ ] `x` で消し、12V を切り、USB を抜く。テープはつないだままでも、外してもよい。

**合格**: 5個とも3色が順に点き、並びが J10 から順。`w` の最大で電流の増え方が 0.1〜0.2A、J10 の 5V が 4.75V 以上、U4 が熱すぎない。12V を切ると消え、入れ直すと点く。

**記録**: 8-1 の J10 の電圧、8-2 の `h`・`l` の J10-2 の電圧、8-3 の電流（`x`・`w` の 16・`w` の 255）、`w` の 255 での J10 の電圧、U4 の熱さ、勝手に光ったか。

## 困ったとき

段階2の手順書の「困ったとき」に加えて:

| 起きたこと | 確かめること |
|---|---|
| 選んだ輪と違う輪の出力が出る・回る | すぐ 12V を切る。IN1・IN2 の線が、ドライバの間で入れ替わっていないか（G19・G23 は U1、G21・G25 は U2、G22・G26 は U3）。i_bench の表示の `wheel:` |
| 回していない輪の `count` が変わる | その輪のエンコーダの線が、回している輪の端子に挿さっていないか。黒（`SGND`）が `PGND` につながっていないか。直らなければ Claude に伝える（エンコーダ側に 10kΩ のプルアップを足す。bom.md） |
| `止めた: 輪n で、出している向きとエンコーダの向きが逆` | その輪の `YELLOW_IS_A`（段 2 の結果）と、モータの赤・白の向き（赤が 1） |
| 3輪の `cps` が 1割より大きく違う | 配線の接触（挿し直す）。その輪のドライバの VM と GND の電圧（TP6 と同じ測り方） |
| 「全部」で電流が 1.0A に張り付いたまま | すぐ止める。1輪ずつ回して、張り付く輪を探す |
| TP6 と TP1 の差が 0.2V 以上 | `VM` の線の太さと接点。TP7 が大きいときは `PGND` の線 |
| 7-2 で LED が点滅しない | JP1 が挿さっているか。U4 の向き。h_vbat を書き込んだか |
| 12V を切っても TP1 がなかなか下がらない | 放電用の抵抗（1kΩ）を C1 の + 足と − 足に 10 秒当てる |
| 8-2 で `h` を送っても J10-2 が 4.5V に届かない | U6 の刻印が AHCT か（AHC だと 3.3V を H と読まない）。U6 の向き。ソケット 1（~1OE）が `SGND` か。`v12:yes` になっているか |
| 8-3 で LED が1個も点かない | テープの向き（入力側の DIN を J10 につないだか）。J10-2 に信号が出ているか（8-2 に戻る）。`v12:yes` か |
