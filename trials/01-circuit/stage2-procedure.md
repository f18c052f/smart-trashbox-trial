# 段階2 組み立てと確認の手順（1輪ぶん）

段階2の回路を、ブレッドボードに少しずつ足しながら確かめる手順。A から H へ順に進む。

- 回路図: [stage2-one-wheel.kicad_sch](./kicad/stage2-one-wheel/stage2-one-wheel.kicad_sch)
- 部品とつなぎ方の正: [bom.md](./kicad/stage2-one-wheel/specs/bom.md)
- プログラムの書き込み方: [firmware/README.md](./firmware/README.md)
- 元にした手順: [circuit-bringup.md](../../docs/inherited/circuit-bringup.md) の E-0〜E-6

**1つの段で新しく足すのは1つだけ。合格しなかったら次へ進まない。** 不合格も [notes.md](./notes.md) の「記録」に書く。
困ったら、その段で止めて Claude に、測った値と起きたことを伝える。

| 段 | 足すもの | 電源 | 電流制限 | 確かめること |
|---|---|---|---|---|
| A | ESP32 だけ | USB | — | 書き込めるか、Flash の大きさ |
| B | ＋可変抵抗 VR1 | USB | — | つまみの読み |
| C | ＋エンコーダ（手で回す） | USB | — | 線の色、カウント、A相の色 |
| D | （配線なし）DualSense | USB | — | つながるか、遅れ |
| E | 12V の入口、5V 電源、電圧の分圧 | 安定化電源 | 0.2A | 12V・5V・分圧の電圧 |
| F | ＋ドライバ、LED 治具 | USB ＋ 安定化電源 | 0.5A | ドライバの電圧、LED の点き方 |
| G | ＋D3・R10・R11、LED 治具をモータに替える | USB ＋ 安定化電源 | 0.5A → 1.0A | モータが回るか、DualSense で回せるか |
| H | ESP32 を 5V 電源から動かす、電池電圧を読む | ① USB ＋ 安定化電源 ② 安定化電源 | 0.2A | 電池電圧の読み、3.3V |

プログラムは A〜H のぶんがすべてできている（G-3 は g_teleop、H は h_vbat。2026-11-15）。

## 0. 始める前に

### 道具

- テスター。使うのは3つ。
  - 直流電圧（V に直線の印）: 黒い棒を「基準」に、赤い棒を測る所に当てる。
  - 抵抗（Ω）: 電源を切った状態で、2点の間の抵抗を測る。
  - 導通（ブザーの印）: 電源を切った状態で、2点がつながっていればブザーが鳴る。
  - **このテスターは電池が減っていて、電圧が高く出る**（A で 3.0V を 3.6V と表示した。電池は交換できない）。
    電圧で合否を決めるときは、下の「比べ測り」を使う。導通は、使う前に棒どうしを触れさせてブザーが鳴ることを確かめる。

**比べ測り**（テスターのずれを、安定化電源の表示で打ち消す）

- 測る**直前に**、回路から外した安定化電源を合格の範囲の下と上の電圧に合わせ、その端子をテスターで測って値を書き留める。
  次に回路を測り、**テスターの値どうしで比べる**。同じテスター・同じレンジ・同じ時刻なら、ずれは両方に同じように乗る。
  - 例（A の 3V3、合格 3.1〜3.5V）: 電源 3.10V を測ると 3.71、3.50V を測ると 4.19 と出たなら、3V3 の値が 3.71〜4.19 の間で合格。
- 電池がさらに減ると、ずれも変わる。**日をまたいだ値や、前に書き留めた値は使わず、毎回その場で測る。**
- 電源の電圧そのもの（TP1）は、テスターではなく**電源の表示**を正とする。
- 範囲の下と上を測り分けなくてよい「未満」だけの確認（TP4 が 3.3V 未満、TP1 が 1V 以下など）は、その電圧の1点だけを測って比べる。

| 段 | 測る所 | 比べるのに使う電源の電圧 |
|---|---|---|
| A・H | 3V3（TP3） | 3.10V と 3.50V |
| C | TP5（エンコーダの電源） | 3.10V と 3.50V |
| E・H | TP2（`+5V`） | 4.75V と 5.25V |
| E | TP4（`VBAT_SENSE`） | 3.30V（これ未満）。目安の 2.16V も測っておくと、期待どおりか分かる |
| 毎回 | 配線を変える前の TP1 | 1.0V（これ以下） |
- 安定化電源。**− は黒の端子に挿す。緑の GND 端子は使わない**（ケースのアースで、出力の − とつながっていない。段階1で分かったこと）。
- データ用の USB ケーブル（充電専用のケーブルでは PC から ESP32 が見えない）。
- ブレッドボード3枚（ESP32 用に2枚、12V 用に1枚）、ジャンパ線、DualSense。

### いつも守ること

1. **安定化電源は、出力を切ったまま電圧と電流制限を合わせてから、出力を入れる。**
   この回路は部品の側で電流を制限していないので、電源の電流制限がそのまま過電流の保護になる。
2. **入れるときは ESP32 が先（USB を挿す）、12V が後。切るときは 12V が先、USB が後。**
   ESP32 が動いていない間にドライバへ 12V が入ると、その瞬間に出力が出ることがある。
3. **USB を挿すあいだは JP1（ESP32 の 5V と 5V 電源をつなぐ線）を外す。** USB の 5V と 5V 電源がぶつかって逆に流れる。GND の線はつないだまま。
4. **配線を変える・プログラムを書き込むのは、12V を切ってから。**
   12V を切っても C1（1000µF）にしばらく電気が残る。配線を変える前に、テスターで TP1（C1 の + 足と − 足の間）が 1V 以下になっているのを確かめる。
5. 熱い・におう・変な音がする・電流が制限値に張り付いて下がらない、のどれかが起きたら、**すぐ 12V を切る**。原因が分かるまで先へ進まない。

### 置き方の約束

- **ESP32 は2枚のブレッドボードにまたがせる。** 緑の端子台の基板は使わない（ESP32-S3 用で、印刷がこのボードと合わない）。
- USB の口を下に向けて置くと、ピンは回路図と同じ並びになる。左の列は上から 3V3 … 5V、右の列は上から GND … CLK。
- 12V の部品（C1、5V 電源 U4、ドライバ U1、D3、C7）は、3枚目の 12V 用ブレッドボードに置く。
  そのブレッドボードの + レールを `VM`（12V）、− レールを `PGND`（モータの電流が流れる GND）にする。
- ESP32 側のブレッドボードの − レールは `SGND`（信号の GND）にする。
- **`PGND` と `SGND` をつなぐのは、C1 の − 足のすぐ横から ESP32 側の `SGND` レールへ渡す線1本（NT1）だけ。**
  ほかの所でつなぐと、モータの電流が ESP32 の GND を通って、エンコーダが数え間違える。
- C1 は、U1 の VM・GND と U4 の VIN のすぐ横に置く。
- モータの赤・白と、エンコーダの4本（青・黒・黄・緑）は、ブレッドボードの離れた所に挿す。
  赤・白を隣の列に挿し間違えると、エンコーダや ESP32 に 12V が入る。
- より線や太い線は、先にピンヘッダのピンかジャンパ線をはんだ付けしてから挿す（段階1と同じ）。
- 電流が流れる線（VM・PGND・モータ）は短くし、1か所に流すのは 1.0A まで（ブレッドボードの接点の定格）。
- レールが真ん中で切れているブレッドボードがある。最初に、テスターの導通でレールの端から端までつながっているかを確かめる。

### ESP32 で使うピン

基板の印刷は `G32` のように書いてある。上から数えた位置も書いておく。

| 印刷 | 列・上から何番目 | つなぐ先 | 使い始める段 |
|---|---|---|---|
| 3V3 | 左 1 | `+3V3`（VR1 の上端、エンコーダの青、U1 の VREF） | B |
| G32 | 左 7 | `VBAT_SENSE`（電池電圧の分圧） | H |
| G33 | 左 8 | VR1 のまん中（ワイパ） | B |
| GND | 左 14 | `SGND` レール | B |
| G13 | 左 15 | R11 → エンコーダの緑 | C |
| 5V | 左 19（いちばん下） | JP1 → 5V 電源の出力 | H |
| GND | 右 1（いちばん上） | `SGND` レール | B |
| G23 | 右 2 | U1 の IN2 | F |
| GND | 右 7 | `SGND` レール | B |
| G19 | 右 8 | U1 の IN1 | F |
| G4 | 右 13 | R10 → エンコーダの黄 | C |

ほかのピンには何もつながない。

## C. ＋エンコーダ（USB。モータは手で回す）

### C-1 モータの6本を調べる（E-0。電気は流さない）

モータをどこにもつながない状態で、テスターの抵抗レンジで測る。

| 測るところ | 期待 |
|---|---|
| 赤 − 白 | 数Ω（モータの巻線） |
| 青 − 黒 | 赤白とは違う値（0Ω ではない）。kΩ 単位の値が出ることがある |
| 赤 − 青 / 黒 / 黄 / 緑 | すべて開放（OL などと表示される） |

**合格**: 6本が、モータの2本（赤・白）とエンコーダの4本（青・黒・黄・緑）にきれいに分かれる。
ここを間違えると、G で 12V がエンコーダに入って壊れる。

### C-2 エンコーダの差し込み口を作り、電圧を測る

**組む**（USB を抜いてから）

- [x] エンコーダ用の4つの列（J3）を作る。青の列 → `+3V3`、黒の列 → `SGND`。
- [x] 黄の列 → R10（4.7kΩ）→ G4（右 13）。緑の列 → R11（4.7kΩ）→ G13（左 15）。R10・R11 は ESP32 の近くに置く。
  手元にあれば、ここで入れておく（12V を使わない C では無くてもよい。G の前には必ず入れる）。
- [ ] まだエンコーダの線は挿さない。

**確かめる**

- [x] USB を挿し、[c_encoder](./firmware/c_encoder/c_encoder.ino) を書き込む。
- [x] テスターで、黒の列（黒い棒）と青の列（赤い棒）の間を測る（TP5）。**約 3.3V**。
- [ ] USB を抜き、エンコーダの4本（青・黒・黄・緑）をそれぞれの列に挿す。モータの赤・白はどこにも挿さず、先が何にも触れないようにする
  （軸を手で回すとモータが発電して、赤・白の間に数 V が出る）。

### C-3 手で回して数える

- [x] USB を挿し、シリアルモニタを開く（行末は「改行」）。
- [x] 軸を止めているあいだ、`count` が変わらないこと。
- [x] 出力軸に印を付け、`r` を送ってから、**正転**（軸側から見て時計回り）にちょうど 10 回転させる。`count` を書き留める。3回くり返す。
- [x] 逆向きに 10 回転させ、`count` が同じくらいの大きさで負になること。

**合格**: 止まっているあいだ数えない。10 回転の `count` が毎回ほぼ同じ（目安 8000〜8700。10 回転で ±数カウントなら十分）。

**記録**: 10 回転の `count`（3回ぶん）と、その 1/10（出力軸1回転のカウント）。
正転で `count` が**増えた**ら黄が A相、**減った**ら緑が A相。これは F・G のプログラムに入れる。

## E. 12V の入口・5V 電源・電圧の分圧（安定化電源 0.2A。USB は抜く）

ESP32 は使わない（USB を抜いたまま）。

**組む**

- [x] 12V 用ブレッドボードに、XT60（J1）の + → ヒューズ F1 → `VM` レール、J1 の − → `PGND` レール。
- [x] C1（1000µF）: **+ 足を `VM`、− 足を `PGND`**（缶の帯（− の印）がある側が − 足）。逆に付けると破裂・発火する。
- [x] U4（BP5293-50）: **印刷面で 1 番ピンを確かめてから**挿す。1 VIN → `VM`、2 GND → C1 の − 足のすぐ横、3 VOUT → `+5V` の列（TP2）。
  並びを間違えると壊れる。
- [x] NT1: C1 の − 足のすぐ横から、ESP32 側の `SGND` レールへ線を1本。
- [x] R1（100kΩ）: `VM` → `VBAT_SENSE` の列。R2（22kΩ）: `VBAT_SENSE` の列 → `SGND`。
- [x] C6（0.1µF）: `VBAT_SENSE` の列 → `SGND`。`VBAT_SENSE` の列は G32 の近くに作るが、**G32 にはまだつながない**。
- [x] `+5V` の列は ESP32 の 5V ピンにつながない（JP1 は外したまま）。

**電源を入れる前に**（テスター。電源も USB もつながない）

- [x] J1 の + と − の間（`VM` − `PGND`）でブザーが鳴らない。抵抗レンジでは、C1 が充電されて値がだんだん上がるのは正常。
- [x] C1 の + 足が `VM`、U4 の 1 番が `VM`、3 番が `+5V` の列（もう一度、目で確かめる）。
- [x] `+5V` の列と ESP32 の 5V ピンの間でブザーが鳴らない。`VBAT_SENSE` の列と G32 の間でも鳴らない。
- [x] NT1 の線を一度抜いて、`PGND` と `SGND` の間でブザーが鳴らないこと。鳴ったら、ほかの所でつながっている。確かめたら NT1 を戻す。

**電源を入れる**

- [x] 安定化電源の出力を切ったまま、**12.0V・0.2A** に合わせる。XT60 をつなぎ、出力を入れる。
- [x] 電源の電流表示がほぼ 0（0.1A 未満）。0.2A に張り付いたらすぐ切る（短絡か、C1・U4 の向き）。

**測る**（黒い棒を C1 の − 足に当てる）

| 測る所 | 期待 |
|---|---|
| TP1: C1 の + 足 | 12.0V（電源の表示と比べる） |
| TP2: U4 の 3 番（`+5V`） | 4.75〜5.25V |
| TP4: `VBAT_SENSE`（黒い棒は `SGND` レール） | 約 2.16V。**3.3V 未満**であること。超えていたら G32 には絶対につながない |

**合格**: 電流が張り付かない。熱いもの・におうものが無い。3つの電圧が期待どおり。

**記録**: 電流、TP1（テスターの値と電源の表示）、TP2、TP4。

- 段階1で TP1 が 11.7V だった理由（テスターと電源の表示の差か）も、ここで分かる。

## F. ＋ドライバ U1 と LED 治具（USB ＋ 安定化電源 0.5A）

ESP32 は USB で動かす。JP1 は外したまま。

**組む**（12V を切り、TP1 が 1V 以下、USB を抜いてから）

- [x] U1（AE-TB67H450）: モジュールの印刷で 1〜8 の名前を確かめて挿す。

  | U1 の端子 | つなぐ先 |
  |---|---|
  | 1 GND | `PGND`（C1 の − 足の近く） |
  | 2 IN2 | ESP32 の G23（右 2） |
  | 3 IN1 | ESP32 の G19（右 8） |
  | 4 VREF | `+3V3` |
  | 5 VM | `VM`（C1 の + 足の近く） |
  | 6 OUT1 | モータ用の列 J2-1（あとでモータの赤） |
  | 7 RS | `PGND` |
  | 8 OUT2 | モータ用の列 J2-2（あとでモータの白） |

- [x] C7（0.1µF）: U1 の VM と GND の**すぐ横**に、VM − `PGND`。
- [x] C10（0.1µF）: U1 の VREF のすぐ横に、VREF − `PGND`。
- [x] LED 治具（**省いてよい**。省くときは下の「LED で確かめる」をテスターの確認に替える）: 赤 LED と緑 LED を逆向きに並べ、1kΩ を直列にしたもの（1kΩ は **1/4W**。1/8W しか無いときは 2.2kΩ にする）。赤 LED の長い足（アノード）の側を J2-1、1kΩ の先を J2-2 へ。

  ```
   J2-1 ──┬──[ 赤 ▶ ]──┬──[ 1kΩ ]── J2-2
          └──[ ◀ 緑 ]──┘
  ```

  | 列 | 挿す足 |
  |---|---|
  | J2-1 の列 | 赤の**長い足**、緑の**短い足** |
  | まん中の列 | 赤の短い足、緑の長い足、1kΩ の片方 |
  | J2-2 の列 | 1kΩ のもう片方 |

  **赤と緑は逆向き**（長い足が反対の列）。同じ向きにすると、前進で両方が点き、後進でどちらも点かない。

**電源を入れる前に**（テスター）

- [x] U1 の VM と GND を逆にしていない（逆だとドライバが壊れる）。`VM` − `PGND` でブザーが鳴らない。
- [x] 導通: U1 の IN1 ↔ G19、IN2 ↔ G23、RS ↔ `PGND`、VREF ↔ 3V3。IN1 と IN2 が入れ替わっていない。
- [x] NT1 を抜いて `PGND` − `SGND` が鳴らないこと（E と同じ）。確かめたら戻す。

**プログラムを書き込む**（12V は切ったまま）

- [x] USB を挿し、[f_bench](./firmware/f_bench/f_bench.ino) を書き込む。シリアルモニタを開く（115200 baud、行末は「改行」）。f_bench は次のように動く。
  - 書き込み・リセットの直後は何も出力しない。つまみを一度いちばん下（0）に戻すと `準備よし` と出る（回したまま電源を入れても急に動かない）。
  - つまみの量で、前進（IN1 に PWM）の強さが変わる。いちばん上で 100%。強くするときは 1 秒かけて上がる。弱めるときはすぐ。
  - シリアルモニタから文字を送って操作する。

    | 送る文字 | すること |
    |---|---|
    | `b` | 後進にする。つまみが 0 で、止まってから 1 秒たったときだけ受け付ける（早いと「向きは変えない」と出る） |
    | `f` | 前進に戻す（同じ条件） |
    | `s` | すぐ止める。つまみを 0 に戻すまで出さない |
    | `r` | エンコーダの `count` を 0 に戻す |

  - 0.1 秒ごとに `pot`（つまみ %）、`duty`（出している強さ %。+ 前進、− 後進）、`count`・`cps`（エンコーダ）、`ready` を表示する。
- [x] つまみをいちばん下に戻し、`準備よし` が出ることを確かめる。

**電源を入れる**（USB を挿したまま）

- [x] 安定化電源を **12.0V・0.5A** に合わせ、出力を入れる。
- [x] **LED が両方とも消えていること。** 点いていたらすぐ 12V を切る（下の「LED が 0 で点く」）。
  治具を省いたときは、テスターの赤い棒を J2-1、黒い棒を J2-2 に当て、**±10V を超えていないこと**（出力が切れていると、0V 付近で数字がふらつく。それは正常）。

**測る**（E-1 ⑤）

| 測る所 | 黒い棒 | 期待 |
|---|---|---|
| TP6: U1 の VM | C1 の − 足 | TP1 との差が 0.2V 未満 |
| TP7: U1 の GND | ESP32 の GND | ほぼ 0V |

**LED で確かめる**（E-3）

- [x] つまみをゆっくり上げる → **赤だけ**がだんだん明るくなる。いちばん上まで上げて、0 に戻すと消える。
- [x] つまみを 0 に戻して 1 秒待ち、`b` を送って後進に切り替える。同じように上げる → **緑だけ**が点く。0 に戻すと消える。
- [x] つまみを上げたまま `b`・`f` を送る → 「向きは変えない」と出て、点いている色が変わらないこと。
- [x] つまみを上げたまま `s` を送る → すぐ消え、つまみを 0 に戻すまで点かないこと。

**合格**: 0 で両方消える。上げると片方だけ点き、明るさが連続して変わる。向きを変えるともう片方。電流が張り付かない。

**治具を省いたとき: テスターで確かめる**（赤い棒を J2-1、黒い棒を J2-2。直流電圧）

- [x] つまみをいちばん上まで上げる → **＋12V 付近**（同じテスターで測った TP1 とほぼ同じ。テスターが高めに出るので、12V より大きい数字でもよい）。0 に戻すと ±10V を超えなくなる。
- [x] つまみを 0 に戻して 1 秒待ち、`b` を送って後進に切り替え、いちばん上まで上げる → **−12V 付近**。0 に戻すと ±10V を超えなくなる。
- [x] つまみを上げたまま `s` を送る → ±10V を超えなくなり、つまみを 0 に戻すまで出ないこと。
- 途中の位置では、モータがつながっていないので値が安定しない。読まなくてよい。明るさ（強さ）が連続して変わることは、G でモータの速さで確かめる。

**合格**: 0 で ±10V を超えない。いちばん上で前進 ＋12V 付近、後進 −12V 付近。電流が張り付かない。

**記録**: TP6、TP7、電流、LED の点き方（治具を省いたときは、前進・後進のいちばん上での J2-1 − J2-2 の電圧）。

- 切るときは 12V が先、USB が後。

## G. ＋D3・R10・R11、LED 治具をモータに替える（USB ＋ 安定化電源 0.5A → 1.0A）

**組む**（12V を切り、TP1 が 1V 以下、USB を抜いてから）

- [x] D3（P6KE18A）: **帯のある側（カソード）を `VM`**、反対を `PGND`。U1 の近く。
  逆に付けると、電源を入れた瞬間に電流制限に張り付く。
- [x] R10・R11 が入っていること（C で入れていなければここで入れる）。
- [x] LED 治具を外し、モータの赤を J2-1、白を J2-2 に挿す。C3（0.1µF）はモータの端子に付いたまま。
- [x] エンコーダの4本は C と同じ所。
- [x] モータは机の上でテープなどで押さえ、軸と車輪が何にも触れずに回れるようにする（浮かせる）。

**電源を入れる前に**（テスター）

- [x] モータの赤・白の列と、エンコーダの4つの列の間で、ブザーが鳴らない。
- [x] エンコーダの黒の列が `SGND` につながっている（`PGND` や J2-2 ではない）。
- [x] D3 の帯が `VM` 側。

### G-1 指令を出していなければ回らない（E-1 ⑦。0.5A）

- [x] USB を挿す（f_bench のまま）。つまみを 0 に戻す。
- [x] 安定化電源を **12.0V・0.5A** で入れる。**モータが回らない**こと。電流がほぼ 0。

### G-2 つまみで回す（E-4。1.0A）

- [x] 電流制限を **1.0A** に上げる。
- [x] つまみを 0 → いちばん上 → 0 とゆっくり往復させる。引っかかり・段付き・うなりが無いか見る。
  回っているとき、シリアルモニタのエンコーダのカウントが**増える**こと（C で決めた A相の向き）。
- [x] いちばん上で数分回し、U1 のモジュールに指を近づけて熱を確かめる（触れないほど熱ければ止める）。電流の幅を書き留める。
- [x] 回しているあいだに TP7（U1 の GND と ESP32 の GND の差）を測る。
- [x] 回り始めの一瞬は 1.0A で頭打ちになってよい。**回っているあいだも 1.0A に張り付いたままなら止める。**

**合格**: 0 で止まっている。全域で滑らかに速さが変わる。カウントが増える。ドライバが触れないほど熱くならない。電流が張り付かない。

### G-3 DualSense で回す（E-6。1.0A）

- [x] 12V を切り、USB を挿したまま [g_teleop](./firmware/g_teleop/g_teleop.ino) を書き込む。シリアルモニタを開く（115200 baud、行末は「改行」）。g_teleop は次のように動く。
  - **L1 を押しているあいだだけ**動く。左スティックの上下で前進・後進、倒した量で強さが変わる。いちばん倒して「上限」（最初は 30%）。
    十字キーの上・下で上限を 10% ずつ変える（10〜100%）。速さの制御はしない（スティックの量をそのまま強さにする）。
  - 強くするときは 1 秒かけて上がる。弱めるときはすぐ。逆に倒すと、出力を 0 にし、0.5 秒たってエンコーダも止まってから逆へ出す。
  - 次のときはすぐ止め、**スティックを中央に戻すまで出さない**（シリアルモニタに `止めた: …` と出る。ライトバーが赤になる）。
    DualSense が切れた、値が 0.25 秒より長く届かない（ウォッチドッグ）、出しているのにエンコーダが回らない（ロック保護。1 秒）、
    出している向きとエンコーダの向きが逆、シリアルモニタから `s`。中央に戻すとライトバーが緑に戻る。
  - L1 を離して止まったときは、もう一度押せばそのまま出る。
  - シリアルモニタから送る文字: `s` すぐ止める、`w` DualSense の値を 1 秒読まない（ウォッチドッグの試験）、`r` count を 0 に戻す。
  - 0.1 秒ごとに `L1`、`stick`（%）、`max`（上限 %）、`duty`（出している強さ %。+ 前進）、`count`・`cps`、`gap`（値が届く間隔の最大 ms）、`ready` を表示する。
- [x] 安定化電源を **12.0V・1.0A** で入れる。DualSense の PS ボタンを押してつなぐ（D でペアリング済み。つながらなければクリエイト＋PS を長押し）。
  ライトバーが緑になり、短く振動する。モータは回らない。
- [x] スティックに触らずに、`gap` のふだんの値を見る（D と同じくらいか。**いつも 100ms を超えるなら止めて Claude に伝える**。ウォッチドッグの 250ms に近すぎる）。
- [x] **L1 を押していないとき**、スティックを倒しても回らない（`duty:0`）。
- [x] L1 を押しながらスティックを上に倒すと前進し（`count` が増える）、倒した量で速さが変わる。L1 を離すとすぐ止まる。
- [x] スティックを下に倒すと、`向きを変える: 止まるのを待つ` → `後進にした` と出てから逆に回る（`count` が減る）。前進に戻すときも同じ。
- [x] 十字キーの上で上限を上げ（`上限 40%` などと出る）、速くなることを見る。終わったら下で 30% に戻す。
- [x] 回しているあいだに `w` を送る → すぐ止まり、`止めた: ウォッチドッグ` と出る。1 秒後に値が戻っても、スティックを中央に戻すまで回らない。
- [x] 回しているあいだに `s` を送る → すぐ止まる。スティックを中央に戻すまで回らない。
- [x] 回しているあいだに DualSense の電源を切る（PS ボタンを約 10 秒押す）→ すぐ止まり、`止めた: DualSense が切れた` と出る。
  PS ボタンを押してつなぎ直せる。
- [x] （してもよい）ロック保護: **止まっているときに**輪（タイヤ）を手で持って回らないようにしてから、L1 を押してスティックをいっぱいに倒す
  → 約 1 秒で止まり、`止めた: 出しているのにエンコーダが回らない` と出て、DualSense が振動する。電流が 1.0A に張り付いたままにならない。
  回っている輪をつかんで止めない（軸のイモネジに指を挟む）。

**合格**: L1 を押していないと回らない。押すと倒した量で回り、離すとすぐ止まる。逆に倒すと止まってから逆に回る。
`w`・`s`・DualSense の電源を切る、のどれでもすぐ止まり、スティックを中央に戻すまで回らない。前進で `count` が増え、後進で減る。
`止めた: 出している向きとエンコーダの向きが逆` が出ない（出たら `YELLOW_IS_A` か、モータの赤・白の向き）。

**記録**: G-2 の電流の幅・熱・TP7、G-3 の `gap`（ふだんと最大）、遅れの感じ、上限ごとの電流、気になった動き。ロック保護を試したなら、そのときの電流。

- 切るときは 12V が先、USB が後。

## H. ESP32 を 5V 電源から動かす・電池電圧を読む（0.2A）

**組む**（12V を切り、TP1 が 1V 以下、USB を抜いてから）

- [x] **モータの赤・白を J2 から抜く**。ESP32 を 5V 電源から動かしながらモータを回すと、
  電流制限で 12V が下がって ESP32 がリセットするため（bom.md）。
- [x] `VBAT_SENSE` の列を G32（左 7）へつなぐ（E で TP4 が 3.3V 未満だったことを確かめてから）。

### H-1 電池電圧の読み（USB のまま）

- [x] USB を挿し、[h_vbat](./firmware/h_vbat/h_vbat.ino) を書き込む。シリアルモニタを開く（115200 baud）。
  0.5 秒ごとに `raw`（ADC の読み）、`pinmV`（GPIO32 の電圧 mV）、`min`・`max`（読みのばらつき）、`vbat`（分圧の比で割り戻した電圧）が出る。
  12V を入れる前は `raw` が 0（`pinmV` は 142 前後になる。ADC は約 0.15V 未満を読めず、raw 0 を補正するとこの値になる。異常ではない）。
- [x] USB を挿したまま、安定化電源を **12.0V・0.2A** で入れる。`vbat` が 12V 前後になる（係数を決める前なので、少しずれていてよい）。
- [x] 電源の電圧を 10.0V・11.0V・12.0V・12.6V に変え、それぞれで、`pinmV`・`min`・`max`・`vbat` と**電源の表示**を書き留める（テスターはずれているので使わない）。
  変えてから数秒待ち、値が落ち着いてから読む。この表から、読みを電池の電圧に直す係数を決める（Claude が計算する）。
- [x] `注意: 2.45V を超えている` が出たら、それ以上電圧を上げない（分圧の配線を確かめる。12.6V で `pinmV` は約 2270 のはず）。

### H-2 ESP32 を 5V 電源から動かす（E-1 ③）

- [x] 12V を切り、**USB を抜く**。
- [x] JP1: `+5V` の列から ESP32 の 5V（左 19）へ線を1本。
- [x] 安定化電源を **12.0V・0.2A** で入れる。電流が張り付かない（目安 0.1A 未満）。
- [x] TP2（`+5V`、黒い棒は C1 の − 足）が 4.75〜5.25V。TP3（ESP32 の 3V3、黒い棒は `SGND`）が 3.1〜3.5V。
- [x] ESP32 の LED（GPIO2）が 0.5 秒ごとに点滅する（h_vbat が 5V 電源から動いている）。基板の電源の LED が点くだけでは足りない。
  A で GPIO2 の LED が点滅しなかった基板（LED が無い）なら、ここは TP3 で判断する。
- [x] 12V を切り、**JP1 を外す**。次に USB を挿す前に、必ず外す。

**合格**: H-1 で読みが電圧にそってまっすぐ変わる。H-2 で電流が張り付かず、5V・3.3V が出て、ESP32 が動く。

**記録**: H-1 の表（電源の表示、読み）、H-2 の電流、TP2、TP3。

## 困ったとき

| 起きたこと | 確かめること |
|---|---|
| COM ポートが出ない | 基板の電源の LED が点くか。充電専用でないケーブルに替える。ハブを通さず PC に直接挿す。「不明なデバイス」や黄色い印が出たら CP2102 のドライバ（Silicon Labs CP210x）を入れる |
| 書き込みが `Connecting....` で止まる | 基板の BOOT ボタンを押したままにし、% が進み始めたら離す |
| 電流が制限値に張り付く | すぐ切る。C1・U4・D3・U1 の向き、`VM` と `PGND` が触れていないか |
| LED（またはモータ）が、つまみ 0 で点く・回る | すぐ切る。モータはつながない。IN1/IN2 を ESP32 の側と U1 の側で直流電圧で測る（PWM の平均が `3.3V × 強さ` で読める）。ESP32 の側が正しくて U1 の側が違えば配線 |
| 止まっているのにカウントが変わる、回すと数え間違える | 配線と `SGND` のつなぎ方（NT1 だけか）。直らなければ、J3 側（R10・R11 のエンコーダ側）に 10kΩ のプルアップを足す（bom.md） |
| 5V・3.3V が期待から外れる | U4 の向き。5V がモータを回したときだけ外れるなら、U4 の VIN の近くに 10µF を足す（bom.md の「計算と根拠」） |
