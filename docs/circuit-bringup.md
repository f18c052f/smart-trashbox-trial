# 回路に初めて電気を流す手順（E-0〜E-7）

旧リポジトリで作った手順を、引き継ぐ価値のある部分だけに絞ったもの。
回路は [circuit.md](./circuit.md)、測定点 TP1〜TP7 は [circuit.md §9](./circuit.md#9-電圧の測定点) を見る。

## 考え方

- **1段ごとに、新しい未知を1つだけ増やす。** 順番を入れ替えない。
- **合格しなかったら次の段へ進まない。** 不合格も記録する。
- **最初の通電は電流制限つきの安定化電源で行う。LiPo で初通電しない。**
  3S LiPo は短絡すると配線を溶かすほど流せるが、電流制限をかけた安定化電源は止まる。
- モータの前に **LED でドライバの出力を見る**。論理の誤りがあっても、LED なら何も壊れない。
  モータでやると、いきなり全速で逆転することがある。
- 旧リポジトリでは E-0 まで済ませた（配線色と系統は表どおりだった）。回路を組み直すので、E-0 からやり直す。

## どの段でも守ること

1. **ESP32 をリセットしてから VM を入れる。** IN1/IN2 が振られている状態で主電源を入れると、その瞬間に出力が出る。
2. **USB を挿すなら JP1 を外す。** 切るのは 5V だけで、GND はつないだまま。
3. **電流制限を先に設定してから出力を入れる。** この回路は IC 側で電流を制限していないので、電源の電流制限がそのまま過電流保護になる。
4. 発熱・異臭・異音・想定外の電流のどれかがあれば、すぐ電源を切る。原因が分かるまで先へ進まない。

## 段の一覧

| 段 | 内容 | 新しく入る未知 | 電源 |
|---|---|---|---|
| E-0 | 電気を流さずに、線の色と系統を確かめる | ハーネスの色 | なし |
| E-1 | 電流制限つきの電源で、1つずつつないで確かめる | 配線の短絡、電源系 | 安定化電源 |
| E-2 | ドライバを通さず、モータ単体を回す | モータの個体差と回転方向 | 安定化電源 |
| E-3 | LED で、ファームとドライバの論理を確かめる | ファーム＋ドライバ | 安定化電源 |
| E-4 | モータ1個で、開ループで回す | 実際の負荷（電流・発熱・滑らかさ） | 安定化電源 |
| E-5 | LED で、コントローラの疎通を確かめる | 無線とデッドマン | 安定化電源 |
| E-6 | コントローラで輪1個を回し、エンコーダを校正する | エンコーダと速度制御 | 安定化電源 |
| E-7 | モータ3個を机の上で回す | 3輪ぶんの電流と個体差 | 安定化電源 |

床に置いて走らせる（3輪の向きと符号の確認）のは、この後に機体が組み上がってから行う。
そのときはホイールを床から浮かせる台を3つ用意し、浮かせた状態から始める。

## E-0 電気を流さずに線の色と系統を確かめる

テスターの抵抗レンジで、モータから出ている6本を調べる。

| 測るところ | 期待 |
|---|---|
| 赤 − 白 | 数Ω（モータの巻線） |
| 青 − 黒 | 赤白とは別の値（短絡ではない）。ホール IC の内部を拾って kΩ オーダーの値が出ることがある |
| 赤 − 青 / 黒 / 黄 / 緑 | すべて開放 |

**合格**: 6本がモータ対（赤・白）とエンコーダ対（青・黒・黄・緑）にきれいに分かれていること。
ここを間違えると、次の段で 12V がエンコーダへ入って壊れる。

## E-1 電流制限つきの電源で少しずつ確かめる

基板の電源入力（バッテリをつなぐ場所）へ安定化電源をつなぐ。電圧は 12.0V。

| 手順 | すること | 電流制限 | 期待 |
|---|---|---|---|
| ① | 何もつながない状態で ON | 0.2A | 電流がほぼ 0（0.1A 未満）。0.2A に張り付いたら短絡を疑う |
| ② | 5V 出力を測る（TP2） | 0.2A | 4.75〜5.25V |
| ③ | ESP32 の 3V3 を測る（TP3） | 0.2A | 3.1〜3.5V |
| ④ | 分圧の中間点を測る（TP4。まだ GPIO32 につながない） | 0.2A | **3.3V 未満**（12.0V 入力なら約 2.5V）。超えていたら GPIO32 につながない |
| ⑤ | ドライバの VM と GND を測る（TP6 / TP7） | 0.5A | VM は 12.0V との差 0.2V 未満、GND はほぼ 0V |
| ⑥ | エンコーダのコネクタだけ挿して、青 − 黒を測る（TP5） | 0.5A | **約 3.3V。12V に近ければすぐ OFF** |
| ⑦ | モータのコネクタも挿す | 0.5A | **モータが回らない**（まだ指令を出していない） |

**合格**: どの手順でも電流が制限値に張り付かない。発熱・異臭が無い。各測定値が期待どおり。

## E-2 モータ単体を回す

モータを回路から外し、安定化電源に直結する（12.0V、電流制限 2.5A）。

1. 赤を +、白を − につなぎ、回る向きを記録する。**これを「正転」と決める。以降のすべての段の基準になる。**
2. 無負荷電流を記録する。
3. 赤と白を入れ替え、逆に回ることを確かめる。
4. 3個とも行う。

**合格**: 3個とも回る。無負荷電流が3個でおおむね揃う（外れ値の個体をここで見つける）。

## E-3 LED でファームとドライバの論理を確かめる

モータの代わりに LED 治具をドライバの OUT1 − OUT2 へつなぐ。エンコーダはつながない。
ファームは「可変抵抗（GPIO33）の値を読み、そのままデューティにする」だけの最小のもの。PCNT も PID も使わない。
電流制限 0.5A。

### LED 治具

2色の LED を逆向きに並列にし、1kΩ（1/4W）を直列に入れる。

```
 OUT1 ──┬──[ LED赤 ▶ ]──┬──[ 1kΩ ]── OUT2
        └──[ ◀ LED緑 ]──┘
```

電流は (12V − 2V) / 1kΩ ≒ 10mA。LED どうしが順方向電圧でクランプし合うので逆耐圧は気にしなくてよい。
20kHz の PWM なのでちらつかない。

| 指令 | IN1 | IN2 | LED |
|---|---|---|---|
| ゼロ | L | L | 両方消灯 |
| 前進 | PWM | L | 片方が明るさ可変 |
| 後進 | L | PWM | もう片方が明るさ可変 |

### 手順

1. 可変抵抗を絞りきる（0%）。
2. ESP32 をリセットしてから主電源を入れる。
3. **LED が両方とも消えていること**を確かめる。点いていたらすぐ切る。
4. 可変抵抗をゆっくり上げ、**片方だけ**がだんだん明るくなることを見る。100% まで上げて 0% に戻す。

**合格**: 絞りきりで両方消灯、上げると片方だけ点灯、明るさが連続的に変わる、0% で消灯に戻る。

**絞りきりで点灯したら**: IN1/IN2 の動かし方（案B）が効いていない。古いファーム、IN1 と IN2 の配線の入れ替え、古いビルドのどれか。
モータをつないでいたら全速で逆転していた状態なので、原因が分かるまでモータをつながない。

**うまくいかないときの切り分け**（鎖を上流へ1つずつ戻る）:

1. LED が上の表と合うか
2. ドライバの IN1 / IN2 をテスターの DC 電圧で測る。PWM の平均が読めて `3.3V × デューティ` になる
3. ESP32 の GPIO を同じように測る。ここが正しくて IN1/IN2 が違えば配線の問題
4. ドライバの VM に電源が来ているか

## E-4 モータ1個を開ループで回す

LED 治具を外し、モータを1個だけつなぐ。車輪は浮かせる。電流制限 **1.5A**（これが IC の過電流保護を兼ねる）。

1. 可変抵抗を絞りきり、ESP32 をリセットしてから主電源を入れる。モータが動かないことを確かめる。
2. 0% → 100% → 0% とゆっくり往復させ、引っかかり・段付き・うなりが無いか見る。
3. 数分回し、ドライバの熱を確かめる。消費電流の幅を記録する。

**合格**: 絞りきりで止まっている。全域で滑らかに加減速する。ドライバが触れないほど熱くならない。電流制限に張り付かない。

## E-5 LED でコントローラの疎通を確かめる

テレオペ用のファーム（DualSense を Bluetooth で直接つなぐ）を書き込む。モータの代わりに LED 治具。電流制限 0.5A。

**合格**: ペアリングできる。デッドマン（L1 など）を離すと消灯する。押しながらスティックを倒すと点灯し、倒す向きで色が変わる。
接続が切れたら消灯する。再接続できる。十字キーで選んだ輪だけが点く（3輪ぶん治具があれば）。

- 入力の遅れを主観でいいので記録する。
- エンコーダをつないでいないので、少し倒しただけで全点灯することがある（速度制御が飽和するため）。この段では異常ではない。
- Bluetooth 直結がうまくいかなければ、PC 経由（USB シリアル / UDP）に切り替える。

## E-6 コントローラで輪1個を回し、エンコーダを校正する

モータ1個とエンコーダをつなぐ。車輪は浮かせる。

**合格**:

- デッドマンを押していないとき、モータが動かない
- 指令に対して暴走しない（暴走したら、エンコーダが数えていないか符号が逆）
- 計数が回転に比例する
- 出力軸1回転あたりのカウントが 209 前後（11 パルス × 減速比 約19、カウント方法で変わる）
- **A相 / B相 がどの色（黄 / 緑）か確定する**

手で輪を何回か回し、そのときのカウントから分解能を出す。この値をコードに決め打ちしない。

## E-7 モータ3個を机の上で回す

残りの2輪も E-3（LED）→ E-4（モータ）を済ませてから、3輪とも浮かせて回す。

**合格**: 3輪とも回る。挙動に大きな差が無い。合計電流が想定内（電流制限 1.5A なら最大 4.5A）。十字キーで選んだ輪だけが回る。

3輪の向きと符号が正しいかは、床に置かないと分からないので、この段では判断しない。

## 床に置いてからの確認（参考）

機体が組み上がってから行う。台の上でホイールを浮かせた状態から始める。

| 確認すること | なぜ |
|---|---|
| 各モータの回転方向とハーネスの対応 | 1本でも極性が逆だと、前進の指令でスピンする |
| エンコーダの符号（正転でカウントが増えるか） | 逆だと速度制御が正帰還になる |
| デッドマンを離したら即停止するか | 指令ウォッチドッグの発火試験 |
| コントローラの電源を切ったら即停止するか | 同上。固定側との通信が途絶えたときの停止の予行にもなる |
| 前に倒したらまっすぐ進むか（スピン・カニ歩きしないか） | 輪の番号と符号の整合 |
| 輪を手で押さえたらロック保護が働くか | モータロック保護の発火試験 |
| 手動で正方形を走らせ、出発点とのずれを見る | オドメトリのずれを固定側なしで確かめる |
