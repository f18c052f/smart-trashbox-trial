# docs

投げられたゴミの落下地点を空中で予測し、床を走るゴミ箱が移動して受け止めるシステムを作る。
元動画: [勝手に入るゴミ箱作った Smart Trashbox](https://www.youtube.com/watch?v=NqDTE6dHpJw)

## 置き場所

| 場所 | 内容 |
|---|---|
| [trial-plan.md](./trial-plan.md) | トライアル計画のたたき（回路・ゴミ箱・プロトタイプ・シミュレーション） |
| [inherited/](./inherited/README.md) | 旧リポジトリ `smart-trashbox-tribute` から引き継いだドキュメント。前提・目次は [inherited/README.md](./inherited/README.md) にある |

- `inherited/` は引き継いだ時点の記録として残し、書き換えも追加もしない。
- このリポジトリで新しく書くドキュメントは `docs/` の直下に置く。トライアルで `inherited/` の想定値や図を置き換えたときも、
  新しい文書を `docs/` の直下に作り、元の文書へのリンクを付ける。
