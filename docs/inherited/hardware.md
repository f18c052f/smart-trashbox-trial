### JGB37-520（商品仕様）

| 項目 | 値 |
|---|---|
| 電圧 | DC 12V |
| 無負荷回転数 / 定格回転数 | 530 RPM / 約 407 RPM |
| 減速比 | 約 19:1（公称。実際は割り切れない比のことが多い） |
| 定格トルク / 最大トルク | 約 2.2 / 約 3.1 kgf·cm |
| ストール電流 | 約 2.3 A |
| シャフト | 6mm D カット、長さ約 15.5mm |
| エンコーダ | ホール式、電源 3.3V / 5V、11 パルス/モータ1回転。出力軸1回転あたり約 209（11 × 約19）。**実際の値はカウント方法で変わるので測って決める** |
| 線 | 6本。赤・白 = モータ電源、青 = エンコーダ VCC、黒 = エンコーダ GND、黄・緑 = A相/B相（どちらが A 相かは仕様に書かれていない） |

⚠️ **黒はエンコーダの GND で、モータ電源の − は白である。**「黒＝GND」と思ってモータ電源を青・黒へ入れると、
エンコーダが壊れる。通電の前にテスターで系統を確かめる（→ [circuit-bringup.md](./circuit-bringup.md) の E-0）。

60mm ホイールでの理論周速: 無負荷 530RPM で約 1.66 m/s、定格 407RPM で約 1.28 m/s。
負荷・スリップ・電圧降下で実際はこれより遅くなる。

### ハブ（メーカー資料の値）

| 項目 | 値 |
|---|---|
| 内径 | Ø6、**真円**（D 形でもキー溝付きでもない） |
| フランジ外径 / 厚さ | Ø28 / 4mm |
| ボス | Ø12 × 12mm |
| 全長 | 16mm（シャフト 15.5mm とほぼ同じ長さなので、軸方向の調整代は無い） |
| ボルト円 | Ø21、3-Ø3.2 |
| 止めネジ | M4 × 1 |
| 重さ | 12g |

**つながり方**: モータの 6mm D シャフト → ハブ（加工なしで付く）→ ボスをホイールの Ø12.5 の穴へ入れてボルト円でネジ止め。
この組み合わせで組めることは現物で確認済み。

⚠️ **トルクを伝えるのは M4 のイモネジ1本だけ。** ハブの穴は真円なので、イモネジがシャフトの D カットの
平らな面に当たっていれば保持でき、丸い面に当たっていると滑る。
**滑ってもエンコーダはモータ側で回り続けるので、制御からは気付けない。** 組むときに平面へ当てる。

### AE-TB67H450（データシート・アプリケーションノートより）

| 項目 | 値 |
|---|---|
| 入力 | IN1 / IN2。H レベル 2.0〜5.5V なので ESP32 の 3.3V で動く。**内部に 100kΩ のプルダウンがある** |
| 真理値表 | (IN1, IN2) = (L, L) ストップ / (H, L) 正転 / (L, H) 逆転 / (H, H) ブレーキ |
| 論理電源 | 別のピンは無い（VM から内部で作る） |
| 端子 | 8本: GND / IN2 / IN1 / VREF / VM / OUT1 / RS / OUT2 |
| 過電流保護（ISD） | 標準 4.9A でラッチ。電源の入れ直しか、IN1/IN2 を 1ms 以上 L にしてから再指令で解除 |
| 熱 | 許容損失 2.85W（4層基板での値）。ストール 2.3A を流し続けると約 3.2W で超える |
| センス抵抗 | **モジュールには付いていない**（テスターで確認済み）。旧設計では付けないことにした（→ [circuit.md](./circuit.md#4-電流の守り)） |

ストール電流 2.3A はこのドライバの能力に近い。モータを長くストールさせないことをソフトの保護で担保する前提で選んだ。

## 4. ゴミ箱

| 項目 | 内容 |
|---|---|
| 品名 | キャンドゥ「ダストボックス丸」＝ **山田化学 No.335**（JAN 4965534335027） |
| 仕様 | 丸型、PP、6.9L、フタなし、110円 |
| 買い直し | アスクルなどの通販で単品約160円。100円ショップは在庫が入れ替わると同じ品が手に入らなくなるので、こちらが当てになる |

⚠️ **パッケージの寸法表記（φ220 × H224）は実物と合わない。** φ220 は開口の外径である。旧リポジトリでの採寸値は [reference-measurements.md](./reference-measurements.md#4-ゴミ箱山田化学-no335) にある（参考値）。

選んだ基準（実店舗の品揃えを調べて決めた）:

- 丸型であること。角形は方向によって開口の広さが変わる。
- 開口の内径 φ200 以上。100円ショップの丸型は φ215〜225 あたりが上限で、φ240 以上は見つからなかった。
- 300g 以下。軽さが欲しいのは転倒対策ではなく加速のため。
- 高さ 200〜300mm（寝かせた空き缶が収まる深さ）。
- 脚付き・丸底は不可。ほぼ全品に入れ子用のテーパーがあるので、テーパーの緩いものを選ぶ。
- フタ・スイング・内枠は開口を狭めるので、無いものを選ぶ。
- 5L〜7L が狙い目。それより大きくしても径はほとんど変わらず、高さだけ伸びる。
