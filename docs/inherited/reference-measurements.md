# 旧リポジトリでの採寸値（参考値）

旧リポジトリで手元の部品をノギスなどで測った値。**参考値として**残す。

- **合否条件や設計の確定値にしない。** トライアルで使う部品は現物で測り直し、食い違ったらそちらを正とする。
- 手で測った値で、誤差があることは測った時点で承知していた。
- 「導出」と書いた値は、測った値から計算したものである。測ってはいない。
- メーカーの公表値は [hardware.md](./hardware.md) にある。公表値と食い違う値は、ここではそのことを書いた。

| 取付穴 | 4つ、長方形に並ぶ | 2026-09-10 | |
| 取付穴の中心距離 | 22.9mm（モータ軸方向）× 29.6mm（接線方向） | 2026-09-10 | 向きはノギスを当てた写真で確定 |
| 取付穴の径 | 約 2.7mm（手で測った値） | — | M3 は通る。設計では呼び径 3.2mm として扱っていた |
| 取付フランジの厚さ | 3.2mm | 2026-09-14 | 角が丸みを帯びていて、一点の値が厚さを代表しない。旧設計はこの値を使わず、上限 6.0mm でボルト長を決めた |
| 取付面 → 接地点（鉛直） | 60.0mm | 2026-09-03 | 駆動ベースの板の下面を床から何 mm に置くかを決める値 |
| 取付面 → ホイール中心 | 33.9mm | 2026-09-03 | **軸方向に測ったかは確かめていない**（下記） |
| 取付面 → ブラケットの最下点（鉛直方向の張り出し） | 40.2mm | 2026-09-14 | **床からの高さではない**（下記） |
| ブラケットの最下点（床から） | 19.8mm | — | 導出（60.0 − 40.2）。車軸中心より 9.15mm 下なので、ブラケットはモータ胴体を中心より下まで抱えている |

- **33.9mm の向き**: 取付面 → 接地点 60.0 と同じく鉛直に測ったのだとすると、差の 26.1mm がホイール半径（約 30mm）と合わない。
  そのため軸方向に測った値と読んだ。ただし、これは整合から推した結論で、測った向きを直接確かめてはいない。
- **40.2mm の取り違え**: 測り方の手引きが「床からブラケットの一番低いところまで」と誤って指示していたため、一度床からの高さとして読んだ。
  実際に測ったのは取付面からの距離である。測り方の指示が誤っていると、返ってくるのは「誤った値」ではなく「別の量の正しい値」になる。
  測り直すときは、どこからどこまでを測るかを図に描いてから測る。
- 2026-09-03 に別途 105.6mm という値があったが、どこを基準に測ったか分からないので捨てた。
